## SECTION 1: "WHEN STUCK, USE THIS" DECISION TREES

### 1.1 Act II Sag → Solution Matrix

**PROBLEM:** Act II feels long, meandering, or loses momentum

**DIAGNOSTIC TREE:**

```
START: Act II feels weak
    │
    ├─→ Are stakes escalating? NO
    │   │
    │   └─→ SOLUTION A: Escalation Mandate
    │       • Each obstacle must be WORSE than previous
    │       • Character must try DIFFERENT approaches each time
    │       • Stakes must INCREASE throughout act
    │       • Map sequences: Is each harder than the last?
    │       **Sources:** Blake (Eight-Sequence), Field (Confrontation), Truby (Opposition Escalation)
    │       **Quick Fix:** Add midpoint that raises stakes dramatically
    │
    ├─→ Is character arc progressing? NO
    │   │
    │   └─→ SOLUTION B: Flaw-Focused Obstacles
    │       • Every obstacle should expose character flaw
    │       • Failures should result FROM the flaw
    │       • Force character to confront flaw repeatedly
    │       • Midpoint = realization about flaw (doesn't yet change)
    │       **Sources:** Truby (Character Problem), Seger (Character Spine), McKee (Arc)
    │       **Quick Fix:** Ensure each sequence failure connects to same core flaw
    │
    ├─→ Are scenes causally connected? NO
    │   │
    │   └─→ SOLUTION C: Cause-Effect Chain Repair
    │       • Every scene's disaster must create next scene's goal
    │       • Map the chain visually (index cards)
    │       • Find and fix breaks in causality
    │       • Delete scenes that don't flow from previous/to next
    │       **Sources:** Field (Causal Progression), Blake (Sequence Method), Giglio Test
    │       **Quick Fix:** Ask of each scene: "Does this scene REQUIRE the next scene?"
    │
    ├─→ Is there a clear midpoint? NO
    │   │
    │   └─→ SOLUTION D: Install Midpoint Reversal
    │       • Add major shift at page 50-60
    │       • Options: False victory, false defeat, major revelation, commitment deepens
    │       • Must reframe entire second half
    │       • Everything after midpoint should feel different
    │       **Sources:** Field (Midpoint), Seger (Turning Points), Snyder (All Is Lost)
    │       **Quick Fix:** Page 55 = something happens that changes everything
    │
    └─→ Do subplots intersect main plot? NO
        │
        └─→ SOLUTION E: Subplot Integration
            • Minimum one scene per subplot per sequence
            • Subplots should COMPLICATE main plot
            • Midpoint: Subplots and main plot intersect
            • Supporting characters shouldn't vanish for 20+ pages
            **Sources:** Seger (Subplot Weaving), Truby (Web of Relationships)
            **Quick Fix:** Ensure B-story and C-story appear in each sequence
```

**MULTIPLE SOLUTIONS APPROACH:**
Often Act II sag has MULTIPLE causes. Run through entire tree and implement ALL applicable solutions.

### 1.2 Character Unlikable → Diagnostic Tree

**PROBLEM:** Notes say character is unlikable, unsympathetic, or hard to root for

**DIAGNOSTIC TREE:**

```
START: Character feels unlikable
    │
    ├─→ Does character have redeeming qualities? NO
    │   │
    │   └─→ SOLUTION A: Add "Save The Cat" Moment
    │       • Show character doing something kind in first 10 pages
    │       • Must be ACTIVE kindness (not passive)
    │       • Should be to someone lower-status or vulnerable
    │       • Shows good heart beneath flawed exterior
    │       **Sources:** Snyder (Save The Cat), Truby (Moral Component)
    │       **Quick Fix:** Add scene where character helps someone (pages 5-15)
    │
    ├─→ Is character's goal sympathetic? NO
    │   │
    │   └─→ SOLUTION B: Clarify/Deepen Goal
    │       • Ensure goal connects to universal need
    │       • Show WHY character wants this (backstory wound)
    │       • Make goal relatable even if methods aren't
    │       • Show what character will LOSE if fails
    │       **Sources:** Truby (Desire), McKee (Object of Desire), Seger (Goal Clarity)
    │       **Quick Fix:** Add scene showing what's at stake emotionally
    │
    ├─→ Is character just mean/cynical? YES
    │   │
    │   └─→ SOLUTION C: Show Vulnerability
    │       • Reveal wound that causes defensive behavior
    │       • Show moment of genuine emotion (fear, sadness, longing)
    │       • Have other characters see through the armor
    │       • Show character's cynicism is PROTECTION, not nature
    │       **Sources:** Blake (Incomplete People), Vorhaus (Comic Flaw), Truby (Ghost)
    │       **Quick Fix:** Add scene where mask drops, even briefly
    │
    ├─→ Does character ever fail or struggle? NO
    │   │
    │   └─→ SOLUTION D: Add Struggle/Failure
    │       • Perfect characters = boring characters
    │       • Show character fail at something early
    │       • Make character work HARD for victories
    │       • Show vulnerability through struggle
    │       **Sources:** Seger (Character Arc), McKee (Gap Reality/Expectation)
    │       **Quick Fix:** Make first attempt at goal fail badly
    │
    ├─→ Is character passive? YES
    │   │
    │   └─→ SOLUTION E: Increase Agency
    │       • Character must DRIVE the plot
    │       • Character must make DECISIONS
    │       • Character must ACT, not react
    │       • Convert reactive scenes to active scenes
    │       **Sources:** Seger (Passive Protagonist Problem), Field (Active Hero)
    │       **Quick Fix:** Have character initiate each sequence's action
    │
    └─→ Is character one-dimensional? YES
        │
        └─→ SOLUTION F: Add Layers (Seger's 7-Layer System)
            • Layer 1 (WHO): Physical/social foundation
            • Layer 2 (WHAT): Behavioral patterns  
            • Layer 3: Conscious goal (what they SAY they want)
            • Layer 4: Unconscious need (what they ACTUALLY need)
            • Layer 5 (HOW): Methods/approach style
            • Layer 6 (WHY): Backstory/motivation
            • Layer 7: Values/ethics/worldview
            **Source:** Seger (Seven-Layer Character)
            **Quick Fix:** Add layers 3 & 4 (goal vs. need in opposition)
```

**CHARACTER LIKABILITY SPECTRUM:**
Not all characters need to be likable in traditional sense. What they MUST be is:
- Interesting (complex, surprising)
- Understandable (we grasp their logic)
- Active (driving their story)
- Human (vulnerable somewhere)

### 1.3 Scenes Feel Flat → Fix Strategies

**PROBLEM:** Individual scenes lack energy, tension, or purpose

**DIAGNOSTIC TREE:**

```
START: Scene feels flat
    │
    ├─→ Is there clear CONFLICT? NO
    │   │
    │   └─→ SOLUTION A: Add Opposition
    │       • Characters must want incompatible things
    │       • Or: Character vs. environment (obstacle)
    │       • Or: Character vs. self (internal conflict)
    │       • "Talking heads" = no conflict = cut scene
    │       **Sources:** McKee (Scene Design), Seger (Scene Purpose), Blake (Conflict)
    │       **Quick Fix:** Give second character opposite goal in this scene
    │
    ├─→ Does scene TURN (value shift)? NO
    │   │
    │   └─→ SOLUTION B: Add Value Change
    │       • Every scene must shift an emotional value
    │       • Hope→Despair, Trust→Suspicion, Love→Hate, etc.
    │       • Map: What value at scene START vs. END?
    │       • If same = scene probably unnecessary
    │       **Sources:** McKee (Value Shift), Chitlik (Scene Energy)
    │       **Quick Fix:** Ensure scene ends emotionally different than it began
    │
    ├─→ Are stakes clear? NO
    │   │
    │   └─→ SOLUTION C: Clarify Stakes
    │       • What does character LOSE if fails in this scene?
    │       • Must be specific and immediate
    │       • Show consequence of failure
    │       • Raise what's at risk
    │       **Sources:** Seger (Scene Stakes), Truby (Pressure)
    │       **Quick Fix:** Add line establishing what happens if character fails
    │
    ├─→ Does scene enter too early? YES
    │   │
    │   └─→ SOLUTION D: Enter Late
    │       • Cut first 1-2 pages of scene
    │       • Enter at moment of conflict
    │       • Skip setup, start in media res
    │       • Reader doesn't need to see character arrive, order coffee, etc.
    │       **Sources:** Seger (Enter Late/Exit Early), Field (Scene Economy)
    │       **Quick Fix:** Delete everything before first moment of tension
    │
    ├─→ Does scene exit too late? YES
    │   │
    │   └─→ SOLUTION E: Exit Early
    │       • End at climactic moment (disaster/revelation)
    │       • Cut aftermath, resolution, transition
    │       • Leave on moment of maximum tension
    │       • Don't show character leaving, processing, etc.
    │       **Sources:** Seger (Enter Late/Exit Early), Blake (Scene Momentum)
    │       **Quick Fix:** Delete everything after peak emotional moment
    │
    ├─→ Is goal unclear? YES
    │   │
    │   └─→ SOLUTION F: Sharpen Scene Goal
    │       • Character must want something SPECIFIC
    │       • Must be achievable within THIS scene
    │       • Must be clear to audience by page 1 of scene
    │       • BEFORE: "Character wants to feel better"
    │       • AFTER: "Character wants boss to approve vacation request"
    │       **Sources:** Blake (Goal-Conflict-Disaster), Seger (Scene Purpose)
    │       **Quick Fix:** State goal in dialogue or action within first 3 lines
    │
    └─→ For COMEDY: Is there enough comedy? NO
        │
        └─→ SOLUTION G: Add Comic Elements
            • Add character overreaction (exaggeration)
            • Include physical obstacle (pratfall potential)  
            • Insert verbal misunderstanding (language comedy)
            • Contrast serious goal with absurd execution
            • Check: Has 10+ minutes passed without laugh? Problem.
            **Sources:** Blake (Comedy Beat Distribution), Vorhaus (Comic Tool)
            **Quick Fix:** Add one comic complication to otherwise dramatic scene
```

**SCENE REPAIR PRIORITY:**
1. First ensure conflict exists (if not, cut scene)
2. Then ensure value shift (if not, cut or merge)
3. Then optimize entrance/exit timing
4. Finally polish for maximum impact

### 1.4 Tone Is Off → Calibration Guide

**PROBLEM:** Script's tone feels inconsistent, unclear, or wrong for genre

**DIAGNOSTIC TREE:**

```
START: Tone feels off
    │
    ├─→ Is tone consistent throughout? NO
    │   │
    │   └─→ SOLUTION A: Establish Tone in First 5 Pages
    │       • Opening sequence sets tonal contract
    │       • Must signal genre, style, emotional register
    │       • Audience calibrates expectations here
    │       • If comedy: first laugh within 5 pages
    │       • If drama: establish emotional depth immediately
    │       **Sources:** Snyder (Opening Image), Field (First 10 Pages)
    │       **Quick Fix:** Rewrite opening to clearly signal tone
    │
    ├─→ Do different scenes feel like different movies? YES
    │   │
    │   └─→ SOLUTION B: Create Tonal Consistency
    │       • Read script aloud: Do all scenes sound like same voice?
    │       • Check: Would scene X fit in completely different genre? Problem.
    │       • Ensure comedy and drama serve same story
    │       • Map emotional register: Should stay within range
    │       **Sources:** Seger (Tonal Unity), Blake (Genre Purity)
    │       **Quick Fix:** Cut scenes that feel tonally alien to the whole
    │
    ├─→ For COMEDY: Is comedy too cruel? YES
    │   │
    │   └─→ SOLUTION C: Recalibrate Punishment/Power
    │       • Check: Are you punching up (at powerful) or down (at vulnerable)?
    │       • If punching down: redirect target or add self-own
    │       • Ensure character DESERVES the comic punishment
    │       • Add "counter-voice" character who can call out cruelty
    │       **Sources:** Sacks (Benign Violation), Blake (Dark Comedy Ethics)
    │       **Quick Fix:** If victim seems unfairly targeted, shift joke target
    │
    ├─→ For COMEDY: Is premise wearing thin? YES
    │   │
    │   └─→ SOLUTION D: Refresh Comic Arena
    │       • Heightening ≠ getting LOUDER
    │       • Heightening = changing ARENA or POWER dynamics
    │       • Move to new location that tests premise differently
    │       • Introduce new obstacle that requires new tactic
    │       **Sources:** Vorhaus (Heightening), Blake (Premise Variation)
    │       **Quick Fix:** Sequence 5-6 should shift setting or social context
    │
    ├─→ For DRAMA: Are stakes too small? YES
    │   │
    │   └─→ SOLUTION E: Raise Dramatic Stakes
    │       • Personal → Professional → Public → Universal
    │       • Must feel genuinely important to character
    │       • Show what character stands to LOSE
    │       • Connect stakes to character's deepest fear/need
    │       **Sources:** McKee (Stakes Hierarchy), Truby (True Stakes)
    │       **Quick Fix:** Midpoint should double the consequences of failure
    │
    └─→ For DARK COMEDY: Is it too dark or not dark enough?
        │
        └─→ SOLUTION F: Calibrate Comic Distance
            • Test: Would this scene played STRAIGHT be unwatchable?
            • If YES: You have sufficient comic distance (good)
            • If NO: Needs to be DARKER to justify comedy treatment
            • Balance horror with absurdity
            • Maintain ethical center even in darkness
            **Sources:** Blake (Dark Comedy Protocol), Sacks (Taboo Navigation)
            **Quick Fix:** Ensure style (absurdist, satirical) signals comic frame
```

**TONE CALIBRATION CHECKLIST:**
- [ ] Opening 5 pages clearly establish tone
- [ ] All scenes feel like they belong to same movie
- [ ] Comedy and drama serve unified story
- [ ] Emotional register stays within appropriate range
- [ ] Genre signals are clear and consistent
- [ ] Ending tone matches opening promise

### 1.5 Dialogue Too On-The-Nose → Subtext Techniques

**PROBLEM:** Characters state feelings/information directly instead of implying

**DIAGNOSTIC TREE:**

```
START: Dialogue feels on-the-nose
    │
    ├─→ Are characters stating emotions directly? YES
    │   │
    │   └─→ SOLUTION A: Say Opposite or Deflect
    │       • Character says OPPOSITE of what they feel
    │       • Or deflects to different topic
    │       • Or changes subject when uncomfortable
    │       • Audience INFERS true emotion from behavior
    │       **Example:**
    │       • ON-THE-NOSE: "I'm really angry at you"
    │       • SUBTEXT: "No, everything's FINE" (while slamming cabinets)
    │       **Sources:** Seger (Three-Dimensional Dialogue), McKee (Subtext)
    │       **Quick Fix:** Have character lie or deflect when asked directly
    │
    ├─→ Is exposition delivered as dialogue? YES
    │   │
    │   └─→ SOLUTION B: Convert Info → Conflict or Irony
    │       • Never deliver information neutrally
    │       • Embed info in argument or tension
    │       • Use dramatic irony (audience knows, character doesn't)
    │       • Or show through action, not dialogue
    │       **Example:**
    │       • ON-THE-NOSE: "As you know, Bob, we've been married 20 years"
    │       • SUBTEXT: Reveal duration through conflict about anniversary
    │       **Sources:** Seger (Exposition Economy), Field (Show Don't Tell)
    │       **Quick Fix:** Cut exposition or embed in scene with opposing goals
    │
    ├─→ Do all characters sound the same? YES
    │   │
    │   └─→ SOLUTION C: Differentiate Character Voices
    │       • Each character needs distinct: vocabulary, rhythm, concerns
    │       • Education level affects word choice
    │       • Profession affects terminology
    │       • Personality affects syntax
    │       • Test: Cover character names—can you tell who's speaking?
    │       **Sources:** Blake (Character Voice), Seger (Dialogue Differentiation)
    │       **Quick Fix:** Give each character a speech pattern "tic" or recurring phrase
    │
    ├─→ Is there too much dialogue? YES
    │   │
    │   └─→ SOLUTION D: Cut 30%, Replace With Action
    │       • First pass: Delete one-third of dialogue
    │       • Replace with visual behavior showing same thing
    │       • "Show don't tell" applies to dialogue too
    │       • Silence can be more powerful than speech
    │       **Sources:** Seger (Dialogue Economy), Field (Visual Storytelling)
    │       **Quick Fix:** For each speech, ask "Could image show this instead?"
    │
    └─→ Does dialogue sound written, not spoken? YES
        │
        └─→ SOLUTION E: Make Speech Natural
            • Read aloud (essential test)
            • Use contractions ("I'm" not "I am")
            • Allow interruptions and overlaps
            • Include incomplete sentences
            • Remove formal grammar in casual scenes
            • Add hesitations, false starts
            **Sources:** Blake (Natural Speech), Seger (Dialogue Reality)
            **Quick Fix:** Record yourself improvising the scene, transcribe rhythms
```

**SUBTEXT CREATION METHOD:**
1. Write scene on-the-nose first (get clarity)
2. Identify what each character REALLY wants/feels
3. Rewrite so they say something ELSE
4. Ensure behavior reveals true emotion
5. Test: Can audience infer truth? If yes, it works.

## SECTION 2: PROBLEM-SOLUTION MATRICES

### 2.1 Top 25 Screenwriting Problems with Multiple Solutions

**Format:** Problem → Diagnosis → Multiple Solution Paths → Methodology References

---

#### PROBLEM 1: Weak or Late Catalyst

**Diagnosis:** Story doesn't start; opening meanders without inciting incident

**Solution Path A - Move Catalyst Earlier:**
- Catalyst must occur pages 1-15 (ideally 10-12)
- Make it PHYSICAL action (not just emotional realization)
- Should be unmistakable event
- **Sources:** Field (Paradigm), Snyder (Catalyst), Seger (Setup)

**Solution Path B - Strengthen Catalyst:**
- Must fundamentally disrupt protagonist's world
- Can't be ignored or easily resolved
- Forces protagonist toward main story
- **Sources:** McKee (Inciting Incident), Truby (Opportunity)

**Solution Path C - Ensure Proper Response:**
- Follow catalyst with clear protagonist response
- Show how this changes protagonist's life
- Build toward Act I commitment (Plot Point 1)
- **Sources:** Field (First Act), Blake (Debate Section)

**Quick Page-Specific Fix:**
- Page 10-15: Catalyst happens
- Page 15-25: Protagonist resists/debates
- Page 25-30: Plot Point 1 = commitment to journey

---

#### PROBLEM 2: Protagonist Is Passive

**Diagnosis:** Things happen TO character instead of character driving story

**Solution Path A - Convert Reactions to Actions:**
- Review each scene: Is protagonist initiating or reacting?
- Rewrite reactive scenes as active decisions
- Character should start each sequence's action
- **Sources:** Seger (Active Hero), Field (Protagonist Drive)

**Solution Path B - Give Character Clear Goal:**
- Must be specific (not vague "be happy")
- Must be achievable through action
- Must require effort/struggle
- State explicitly by page 30
- **Sources:** Truby (Desire Line), McKee (Object of Desire)

**Solution Path C - Force Decisions:**
- Each act break = protagonist must CHOOSE
- Can't have decisions made FOR them
- Show decision-making process
- Make decisions HARD (competing values)
- **Sources:** McKee (Dilemma), Seger (Choice Points), Truby (Crisis)

**Solution Path D - Remove Helpers:**
- If sidekick does all the work, problem
- Protagonist must solve own problems
- Helpers can assist but not solve
- **Sources:** Snyder (Hero's Journey), Campbell (Allies)

**Quick Fix:**
- Scan script for: "Character watches X happen" → Rewrite to "Character MAKES X happen"
- Every plot point should be protagonist's decision or action

---

#### PROBLEM 3: Unclear Theme

**Diagnosis:** Story lacks philosophical coherence; feels like "stuff happens"

**Solution Path A - Define Central Question:**
- Frame theme as QUESTION not statement
- Question should generate debate
- Must have multiple valid answers
- **Sources:** Seger (Central Question), Truby (Moral Argument)

**Solution Path B - Four-Channel Expression:**
- Channel 1: Events (plot embodies theme)
- Channel 2: Character Decisions (choices reveal values)
- Channel 3: Images (visual metaphors)
- Channel 4: Dialogue (multiple perspectives, not preaching)
- **Sources:** Seger (Theme Integration), McKee (Controlling Idea)

**Solution Path C - Credible Opposition:**
- Opponent must voice COUNTER-theme
- Must be persuasive (even if "wrong")
- Creates thematic debate through conflict
- **Sources:** Truby (Opponent's Moral Need), McKee (Counter-Values)

**Solution Path D - Test Through Character Arc:**
- Theme = what character learns
- Transformation should PROVE thematic truth
- Opening flaw opposes theme
- Ending change embodies theme
- **Sources:** Truby (Self-Revelation), Seger (Character Spine)

**Quick Fix:**
- Write opponent speech that articulates OPPOSITE worldview persuasively
- If you can't make opposition compelling, theme will feel preachy

---

#### PROBLEM 4: Act III Feels Rushed

**Diagnosis:** Climax underdeveloped, ending abrupt, resolution unsatisfying

**Solution Path A - Extend Climax:**
- Climax should be LONGEST scene (or sequence)
- Build in stages (not single moment)
- Show every element of struggle
- Don't skip to resolution too fast
- **Sources:** Field (Climax Structure), McKee (Climactic Sequence)

**Solution Path B - Ensure All Setups Pay Off:**
- Review Act I & II: What threads were opened?
- Every setup MUST have payoff in Act III
- Check: Character skills, relationships, objects, promises
- **Sources:** Snyder (Setup/Payoff), Seger (Coherence)

**Solution Path C - Include Emotional Resolution:**
- Plot resolution (external goal achieved/lost)
- Character resolution (internal transformation complete)
- Relationship resolution (connection repaired/severed)
- Thematic resolution (question answered)
- **Sources:** Seger (Multiple Resolutions), Truby (New Equilibrium)

**Solution Path D - Add Denouement:**
- Show how victory/defeat affects character's world
- Can be brief (1-3 pages)
- But shouldn't skip immediately to credits
- **Sources:** Field (Resolution), Blake (Final Image)

**Quick Fix:**
- If Act III is <20 pages, probably too short
- Aim for 25-30 pages (feature) or proper proportion (TV)

---

#### PROBLEM 5: Dialogue Exposition

**Diagnosis:** Characters explain backstory or information directly to each other

**Solution Path A - "As You Know, Bob" Test:**
- Characters shouldn't tell each other things they both know
- If character says "As you know..." or "Remember when..." = problem
- Rewrite to show, not tell
- **Sources:** Seger (Exposition), Field (Show Don't Tell)

**Solution Path B - Embed in Conflict:**
- Deliver info DURING argument
- Each character wants different thing
- Info emerges naturally through opposition
- **Sources:** McKee (Exposition Under Pressure), Seger (Scene Purpose)

**Solution Path C - Use Dramatic Irony:**
- Audience knows something character doesn't
- Character's ignorance drives tension
- Info revealed through behavior not explanation
- **Sources:** Williams (Triangle of Knowledge), Seger (Tension)

**Solution Path D - Delay Information:**
- Just because writer knows doesn't mean audience needs to (yet)
- Reveal only when necessary for THIS scene
- Keep audience slightly off-balance
- **Sources:** Seger (Orientation), Blake (Mystery Box)

**Quick Fix:**
- Search script for "remember when," "as you know," "I heard that"
- Each instance = probable exposition problem
- Rewrite to show or cut entirely

---

#### PROBLEM 6: Midpoint Mush

**Diagnosis:** Story loses focus/direction around page 50-60

**Solution Path A - Install Clear Midpoint Event:**
- Page 50-60: Something major must happen
- Options: False victory, false defeat, commitment deepens, major revelation
- Must reframe entire second half
- **Sources:** Field (Midpoint), Snyder (Midpoint Definition), Seger (Turning Points)

**Solution Path B - Opponent Victory:**
- Midpoint = opponent wins a significant battle
- Forces protagonist to new approach
- Raises stakes substantially
- **Sources:** Truby (Opponent Reveals Power), Seger (Opponent Pressure)

**Solution Path C - Character Realization:**
- Protagonist has insight (about self or situation)
- Doesn't fully change yet (that's Act III)
- But approach shifts based on new understanding
- **Sources:** Truby (Revelation), McKee (Recognition)

**Solution Path D - Relationship Shift:**
- Allies become enemies or vice versa
- Love interest complications peak
- Trust broken or established
- **Sources:** Blake (B-Story Intersection), Seger (Relationship Turns)

**Quick Fix:**
- Page 55 must contain clear, unmistakable event that changes trajectory
- After midpoint, story should feel DIFFERENT than before

---

#### PROBLEM 7: Too Many Characters

**Diagnosis:** Audience confused, can't track everyone, some characters vanish

**Solution Path A - Limit Major Characters:**
- Maximum 6-7 major characters (feature)
- Each should have distinct role/function
- More than 7 = difficult to track
- **Sources:** Seger (Character Economy), Field (Character Limit)

**Solution Path B - Combine Minor Characters:**
- Three messengers → one messenger with personality
- Reduce speaking roles
- Give remaining characters more to do
- **Sources:** Seger (Character Consolidation)

**Solution Path C - Cut Characters Who Don't Arc:**
- If character same at end as beginning, probably cut
- Exception: Opponent (consistency is virtue)
- Each major character needs transformation or revelation
- **Sources:** Truby (Character Function), Seger (Arc Necessity)

**Solution Path D - Distinguish Characters Clearly:**
- Each needs: distinct goal, distinct voice, distinct function
- Audience should never confuse Character A with Character B
- Physical/behavioral differentiation in first appearance
- **Sources:** Blake (Character Differentiation), Seger (Clear Distinctions)

**Quick Fix:**
- List all characters with speaking roles
- For each, ask: "What would change if this character were cut?"
- If answer is "nothing," cut them

---

#### PROBLEM 8: Wrong Structure Choice

**Diagnosis:** Story doesn't fit into chosen structure; feels forced

**Solution Path A - Evaluate Structure-Story Fit:**
- Three-act: Most stories (clear beginning/middle/end)
- Hero's Journey: Transformation stories
- Parallel stories: Multiple protagonists equal weight
- Reverse chronology: Mystery/revelation focused
- **Sources:** Seger (Structure Selection), Field (Paradigm Variations)

**Solution Path B - Test Alternative Structures:**
- Try outlining in different structure
- Which feels most natural?
- Which serves theme best?
- Don't force story into ill-fitting framework
- **Sources:** Seger (Structure Flexibility), McKee (Design Choices)

**Solution Path C - Hybrid Structures:**
- Can combine approaches
- Example: Three-act with Hero's Journey beats
- Or: Parallel stories with unified climax
- **Sources:** Seger (Advanced Structures), Truby (Flexible Design)

**Quick Fix:**
- If forcing story into structure feels painful, probably wrong structure
- Trust that organic structure will emerge from story needs

---

#### PROBLEM 9: Scenes Too Long

**Diagnosis:** Individual scenes drag; lose momentum

**Solution Path A - Enter Late:**
- Cut first 1-2 pages of scene
- Skip arrival, greeting, setup
- Start at moment of conflict
- **Sources:** Seger (Enter Late), Field (Scene Economy)

**Solution Path B - Exit Early:**
- End at climactic moment
- Cut aftermath, processing, departure
- Leave on moment of tension
- **Sources:** Seger (Exit Early), Blake (Scene Momentum)

**Solution Path C - Split Multiple Goals:**
- If scene has 2+ goals, probably 2+ scenes
- Each scene = one goal, one conflict, one disaster
- **Sources:** Blake (Goal-Conflict-Disaster), Seger (Scene Purpose)

**Solution Path D - Cut Unnecessary Scenes:**
- Giglio Test: "Could this scene appear anywhere in script?"
- If YES = scene doesn't causally connect (cut it)
- Every scene must be THIS scene, in THIS position
- **Sources:** Blake (Scene Necessity), Giglio Test

**Quick Fix:**
- If scene is >5 pages, scrutinize carefully
- Likely can be trimmed 30-50% through late entry/early exit

---

#### PROBLEM 10: Unclear Genre

**Diagnosis:** Script doesn't fit clear genre; tonally confused

**Solution Path A - Clarify Primary Genre:**
- Every script has ONE primary genre
- Can have secondary genre (dramedy, rom-com, sci-fi thriller)
- But one must be dominant
- **Sources:** Snyder (Genre Definition), Seger (Genre Clarity)

**Solution Path B - Follow Genre Conventions:**
- Each genre has expected beats/structure
- Subvert thoughtfully, but understand rules first
- Audience has genre expectations; don't ignore
- **Sources:** Snyder (Save the Cat Genres), Blake (Genre Requirements)

**Solution Path C - Test Genre Fit:**
- Read 5 scripts in intended genre
- Does your script feel like same family?
- If wildly different, might be wrong genre label
- **Sources:** Seger (Genre Analysis)

**Quick Fix:**
- Complete this sentence: "This is a [GENRE] about [CONCEPT]"
- If you can't, genre is unclear

---

#### PROBLEM 11: Flat Opponent

**Diagnosis:** Antagonist one-dimensional, not credible threat

**Solution Path A - Give Opponent Credible Motivation:**
- Opponent believes they're the hero
- Must have logical reason for opposition
- Should be able to justify actions from their worldview
- **Sources:** Truby (Opponent's Moral Need), McKee (Antagonist)

**Solution Path B - Opponent Pressure Grid:**
- Capability: Can they realistically win?
- Proximity: Are they inside protagonist's life?
- Ideology: Do they voice credible counter-ethic?
- Tactics: Do they escalate across acts?
- **Sources:** Seger (Opponent Pressure)

**Solution Path C - Write Opponent's Persuasive Speech:**
- Draft monologue where opponent convinces neutral jury
- If you can't make it persuasive, opponent too weak
- Audience must understand opponent's perspective
- **Sources:** Truby (Credible Opposition), Seger (Moral Debate)

**Solution Path D - Make Opponent Personal:**
- Best opponents know protagonist intimately
- Share history or connection
- Understand protagonist's weaknesses
- **Sources:** Truby (Personal Opponent), McKee (Intimate Enemy)

**Quick Fix:**
- Opponent should win several battles in Act II
- If protagonist easily overcomes opposition, stakes too low

---

#### PROBLEM 12: Theme Preachy

**Diagnosis:** Theme stated directly instead of proved through events

**Solution Path A - Remove "Theme Speeches":**
- Character shouldn't articulate theme directly
- Cut lines like "What I learned is..." or "The real treasure was..."
- Let audience draw own conclusions
- **Sources:** Seger (Show Don't Tell Theme), McKee (Subtext)

**Solution Path B - Multiple Perspectives:**
- Different characters voice different viewpoints
- No single character speaks for writer
- Theme emerges from CLASH of perspectives
- **Sources:** Truby (Moral Web), Seger (Thematic Debate)

**Solution Path C - Prove Through Events:**
- Character's transformation = thematic proof
- What character LEARNS through experience
- Not what they're TOLD
- **Sources:** Truby (Self-Revelation), McKee (Theme Through Arc)

**Quick Fix:**
- Search for words: "real," "truly," "what matters is"
- Usually signals theme speech (cut or rephrase as question)

---

#### PROBLEM 13: No Visual Style

**Diagnosis:** Script reads like radio play; lacks visual thinking

**Solution Path A - Add Image Systems:**
- Identify 2-3 recurring visual motifs
- Tie to theme
- Show evolution across acts
- **Sources:** Seger (Visual Image Systems), McKee (Visual Design)

**Solution Path B - Show Don't Tell:**
- Convert dialogue exposition to visual behavior
- Character traits shown through action
- Emotional states shown through physicality
- **Sources:** Field (Visual Storytelling), Seger (Action Lines)

**Solution Path C - Use Environment Expressively:**
- Setting should reflect/contrast inner state
- Weather, lighting, space communicate mood
- Physical world is character
- **Sources:** Seger (Environmental Storytelling), McKee (Setting)

**Quick Fix:**
- Ratio test: If dialogue >60% of pages, probably too talky
- Add visual business, physical activity, silent moments

---

#### PROBLEM 14: Unlikable Protagonist (Comedy)

**Diagnosis:** Comic character too mean, cruel, or off-putting

**Solution Path A - Show Vulnerability:**
- Reveal wound causing defensive behavior
- Moment where mask drops
- Show they're aware of own flaws (self-deprecating)
- **Sources:** Blake (Incomplete People), Vorhaus (Comic Flaw)

**Solution Path B - Make Flaw Funny Not Cruel:**
- Oblivious is funnier than mean
- Incompetent is funnier than sadistic
- Self-sabotage is funnier than harming others
- **Sources:** Vorhaus (Comic Flaw Types), Blake (Comedy Character)

**Solution Path C - Give Them a Cause:**
- Fighting for something bigger than self
- Protecting someone vulnerable
- Standing up to bully/authority
- **Sources:** Snyder (Save the Cat), Blake (Moral Component)

**Quick Fix:**
- Add scene where character helps someone
- Even jerks can have one redeeming quality

---

#### PROBLEM 15: Lost Subplot

**Diagnosis:** B-story or C-story disappears for long stretches

**Solution Path A - Subplot Scene Frequency:**
- Minimum one scene per subplot per sequence
- B-story (usually romantic) every 10-12 pages
- C-story every 15 pages
- **Sources:** Seger (Subplot Weaving), Blake (Sequence Structure)

**Solution Path B - Subplot Intersects Main Plot:**
- Subplots should COMPLICATE main story
- Not separate parallel tracks
- Midpoint: Subplots and main plot collide
- **Sources:** Seger (Plot Integration), Truby (Web Structure)

**Solution Path C - Subplot Character Arc:**
- Supporting characters need own mini-transformations
- Don't exist just to serve protagonist
- Own goals, own changes
- **Sources:** Truby (Character Web), Seger (Supporting Characters)

**Quick Fix:**
- Color-code index cards by storyline
- Visual check: Any long gaps in color = missing subplot

## SECTION 4: DIAGNOSTIC WORKFLOWS

### 4.1 "My Script Isn't Working" → Systematic Diagnosis

**WORKFLOW: When you know something's wrong but can't identify what**

#### PHASE 1: GLOBAL ASSESSMENT (30 minutes)

**Step 1: Emotional Response Test**
- Read entire script without stopping to edit
- Track your emotional response by page
- Mark pages where you: felt engaged ✓, lost interest ✗, confused ?
- **Result:** Visual map of problem zones

**Step 2: Structure Skeleton**
- Identify: Catalyst (p.__), PP1 (p.__), Midpoint (p.__), PP2 (p.__), Climax (p.__)
- If any missing or unclear → STRUCTURE PROBLEM
- If all present but weak → Proceed to Phase 2

**Step 3: Character Arc Check**
- Is protagonist different at end than beginning? Y/N
- If NO → CHARACTER PROBLEM (no transformation)
- If YES → Does change feel earned? Y/N
- If NO → CHARACTER PROBLEM (unearned transformation)

**Step 4: Scene Energy Audit**
- Sample every 10th page
- For each scene: Does emotional value shift? Y/N
- If >30% don't shift → SCENE PROBLEM

**Step 5: Theme Clarity**
- Complete: "This story explores whether _________"
- Can you finish sentence clearly? Y/N
- If NO → THEME PROBLEM

**DIAGNOSTIC RESULT:**
Rank problems 1-5 by severity. Address highest-ranked first.

---

#### PHASE 2: TARGETED DIAGNOSTICS (per problem domain)

**IF STRUCTURE PROBLEM:**

Run **Act-by-Act Tests:**

**Act I Test (pages 1-30):**
- [ ] Catalyst occurs pages 10-15?
- [ ] Protagonist clearly established by page 10?
- [ ] World/rules/tone clear by page 15?
- [ ] Plot Point 1 (commitment) by page 25-30?
- [ ] Goal stated explicitly by page 30?

**If 2+ boxes unchecked → Act I needs work**

**Act II Test (pages 30-90):**
- [ ] Midpoint event at page 50-60?
- [ ] Opponent escalates tactics?
- [ ] Stakes increase throughout?
- [ ] Subplots intersect main plot?
- [ ] No single 15-page stretch without turning point?

**If 2+ boxes unchecked → Act II needs work**

**Act III Test (pages 90-120):**
- [ ] Climax is longest scene/sequence?
- [ ] Protagonist drives resolution (not rescued)?
- [ ] All setups from Acts I-II pay off?
- [ ] Both external (plot) and internal (character) resolve?
- [ ] Denouement shows new equilibrium?

**If 2+ boxes unchecked → Act III needs work**

**SOLUTION PATH:**
→ Refer to Section 1.1 (Act II Sag Decision Tree)
→ Refer to Section 2.1 (Structure Problems Matrix)
→ Refer to Section 3.1 (Structure Quick Fixes)

---

**IF CHARACTER PROBLEM:**

Run **Character Architecture Tests:**

**Protagonist Test:**
- [ ] Goal is specific and clear?
- [ ] Need opposes goal (internal conflict)?
- [ ] Flaw causes failures?
- [ ] Has vulnerability/relatability?
- [ ] Actively drives story (not passive)?
- [ ] Transformation arc has 5-7 beats?
- [ ] Arc connects to theme?

**If 2+ boxes unchecked → Protagonist needs work**

**Opponent Test:**
- [ ] Wants same thing OR blocks protagonist's growth?
- [ ] Has credible motivation (believes they're right)?
- [ ] Capable of winning (credible threat)?
- [ ] Tactics escalate across acts?
- [ ] Voices counter-thematic perspective?

**If 2+ boxes unchecked → Opponent needs work**

**Supporting Characters Test:**
- [ ] Each has distinct function?
- [ ] Each has distinct voice?
- [ ] No character could be cut without impact?
- [ ] Supporting cast ≤6-7 major characters?

**If 2+ boxes unchecked → Supporting cast needs work**

**SOLUTION PATH:**
→ Refer to Section 1.2 (Character Unlikable Decision Tree)
→ Refer to Section 2.1 (Character Problems Matrix)
→ Refer to Section 3.2 (Character Quick Fixes)

---

**IF SCENE PROBLEM:**

Run **Scene-by-Scene Audit:**

For problematic scenes, apply **Scene Diagnosis Checklist:**

- [ ] Scene has ONE clear goal?
- [ ] Goal is character-driven (not plot convenience)?
- [ ] Conflict is substantial (not easy)?
- [ ] Scene turns (value shifts)?
- [ ] Scene ends worse than it began (disaster)?
- [ ] Enters late (at moment of conflict)?
- [ ] Exits early (at climactic moment)?
- [ ] Scene duration 2-3 pages (4 max)?
- [ ] Scene connects causally to previous scene?
- [ ] Scene's disaster creates next scene's goal?

**If 3+ boxes unchecked → Scene needs major work**

**SOLUTION PATH:**
→ Refer to Section 1.3 (Scenes Feel Flat Decision Tree)
→ Refer to Section 2.1 (Scene Problems Matrix)
→ Refer to Section 3.4 (Scene Quick Fixes)

**IF THEME PROBLEM:**

Run **Theme Integration Test:**

**Four-Channel Expression Check:**
- [ ] **Events:** Plot embodies thematic question?
- [ ] **Decisions:** Character choices reveal values?
- [ ] **Images:** Visual metaphors support theme?
- [ ] **Dialogue:** Multiple perspectives (not preachy)?

**If 2+ channels missing → Theme needs integration**

**Moral Debate Check:**
- [ ] Opponent articulates OPPOSING worldview?
- [ ] Opposition is persuasive (even if "wrong")?
- [ ] Hero doesn't give "theme speech"?
- [ ] Theme proved through experience (not stated)?

**If 2+ boxes unchecked → Theme too preachy or unclear**

→ Refer to Section 2.1 (Theme Problems Matrix)

#### PHASE 3: SOLUTION IMPLEMENTATION

**Priority Ranking:**
1. **Critical:** Problems that make script unreadable (structure collapse, no character goal, no theme)
2. **Major:** Problems that weaken script significantly (passive protagonist, sagging Act II, flat opponent)
3. **Minor:** Polish issues (scene length, dialogue rhythm, visual style)

**Implementation Order:**
1. Fix STRUCTURE first (foundation)
2. Then CHARACTER (who drives story)
3. Then THEME (what story means)
4. Then SCENE-LEVEL (micro-execution)
5. Finally DIALOGUE (polish)

**Rewrite Pass Strategy:**
- **Pass 1:** Structure (macro-level fixes)
- **Pass 2:** Character (arc, motivation, voice)
- **Pass 3:** Scene (purpose, conflict, turns)
- **Pass 4:** Dialogue (subtext, economy, voice)
- **Pass 5:** Polish (format, typos, rhythm)

**Timeline Estimate:**
- Critical fixes: 2-4 weeks
- Major fixes: 1-2 weeks
- Minor fixes: 1 week
- **Total:** 4-7 weeks for complete revision

**Step 1: Collect All Notes**
- From readers, producers, managers, etc.
- Group similar notes together
- Look for patterns (3+ people say same thing = definitely address)

**Step 2: Translate Emotional Response Into Craft**
- "I don't care" → Character problem
- "It drags" → Pacing/structure problem
- "I'm confused" → Clarity/logic problem
- "It's boring" → Conflict/stakes problem
- "It doesn't feel real" → Motivation/behavior problem

**Step 3: Identify Root Cause**
- Surface note: "Ending is abrupt"
- Root cause: Act III only 15 pages (should be 25-30)
- Fix: Extend climactic sequence

**Step 4: Implement Systematically**
- Don't make random changes
- Use decision trees and matrices in this document
- Each fix should address root cause

**Step 5: Verify Fix**
- After implementing, ask: "Does this address the note?"
- Test with new reader if possible
- Move to next note only when current one solved

### 4.3 "Deadline Approaching" → Triage Strategy

**WORKFLOW: When you have limited time to improve script**

#### SITUATION: 2 WEEKS TO DEADLINE

**PRIORITY TRIAGE:**

**WEEK 1: Critical Fixes Only**

**Day 1-2: Structure Audit**
- [ ] Verify all 5 structural beats are clear and unmistakable
- [ ] If any missing → add NOW (this is foundational)
- [ ] Focus: Catalyst (p.10-15), PP1 (p.25-30), Midpoint (p.55), PP2 (p.85), Climax (p.95-110)

**Day 3-4: Character Goal Clarity**
- [ ] Is protagonist's goal stated clearly by page 30? If NO → add
- [ ] Does protagonist drive every sequence's action? If NO → rewrite
- [ ] Is opponent credible threat? If NO → strengthen motivation

**Day 5-6: Act II Momentum**
- [ ] Does midpoint exist and reframe story? If NO → add major event page 55
- [ ] Do obstacles escalate? If NO → make each sequence harder than last
- [ ] Any 15+ page stretches without turning point? If YES → add complication

**Day 7: Pass-Through for Consistency**
- Read entire script once without stopping
- Mark only CRITICAL issues (logic holes, character name inconsistencies, major plot gaps)
- Fix only what's marked

**WEEK 2: Polish & Delivery**

**Day 8-9: Scene-Level Tightening**
- Cut first line and last line of each scene (enter late/exit early)
- Delete any scenes that fail Giglio test ("could appear anywhere")
- Aim for 2-3 pages per scene maximum

**Day 10-11: Dialogue Pass**
- Search "I feel" and replace with subtext
- Cut 20% of dialogue overall
- Differentiate character voices (give each a verbal tic)

**Day 12: Theme Check**
- Can you state theme as one-sentence question? If NO → clarify
- Delete any "theme speeches" where character states lesson
- Ensure opponent voices opposing worldview

**Day 13: Format & Polish**
- Spell-check, grammar
- Format verification (proper screenplay format)
- Consistent character names, locations
- Page appearance (white space, readability)

**Day 14: Final Read & Submit**
- Read aloud (or have someone else read)
- Fix only glaring errors
- SUBMIT on time (imperfect submitted > perfect late)

- Read entire script
- Mark ONLY: plot holes, logic errors, missing structural beats

**Hour 5-12: Critical Fixes**
- Fix ONLY marked items
- Add missing structural beats
- Clarify protagonist goal

**Hour 13-16: Polish**
- Spell-check
- Format check
- Read aloud once

**Hour 17-24: Buffer & Submit**
- Buffer time for technical issues
- Submit with time to spare
- **REMEMBER:** Imperfect submitted script > perfect late script

## SECTION 5: INTEGRATION CHECKLISTS

### 5.1 Pre-Writing Checklist

**USE BEFORE STARTING DRAFT: Ensures strong foundation**

#### CONCEPT & PREMISE

- [ ] **High-concept pitch:** Can state in 1-2 sentences
- [ ] **Genre clear:** Primary genre identified
- [ ] **Audience identified:** Know who this is for
- [ ] **Unique angle:** What makes this different from similar stories
- [ ] **Emotional core:** Know what emotion story should evoke

**METHODOLOGY:** Snyder (Logline), Truby (Premise), Seger (Concept Testing)

---

#### CHARACTER ARCHITECTURE

- [ ] **Protagonist goal:** Specific, achievable, stated early
- [ ] **Protagonist need:** Opposes goal (internal conflict)
- [ ] **Protagonist flaw:** Causes failures; connected to need
- [ ] **Character arc designed:** 7-beat transformation mapped
- [ ] **Opponent designed:** Credible, motivated, threatens goal
- [ ] **Opponent worldview:** Articulates opposing philosophy
- [ ] **Supporting cast:** ≤6-7 major characters, each distinct function

**METHODOLOGY:** Truby (Character Web), Seger (Seven Layers), McKee (Arc)

---

#### STRUCTURE PLANNING

- [ ] **Structure selected:** Three-act (or alternative chosen deliberately)
- [ ] **Catalyst planned:** Occurs pages 10-15, disrupts protagonist's world
- [ ] **Plot Point 1 planned:** Commitment to journey (pages 25-30)
- [ ] **Midpoint planned:** Major reversal/revelation (page 55)
- [ ] **Plot Point 2 planned:** Darkest moment/recommitment (pages 85-90)
- [ ] **Climax planned:** Protagonist confronts opponent, transformation proves
- [ ] **Act II obstacles:** 4-6 major obstacles planned, escalating
- [ ] **Causality map:** Each sequence flows from previous

**METHODOLOGY:** Field (Paradigm), Snyder (Beat Sheet), Blake (Eight-Sequence), Truby (22 Steps)

---

#### THEME FOUNDATION

- [ ] **Central question defined:** Theme framed as question, not statement
- [ ] **Four-channel plan:** Events, decisions, images, dialogue express theme
- [ ] **Moral debate:** Protagonist and opponent voice opposing worldviews
- [ ] **Thematic wound:** Protagonist's backstory connects to theme
- [ ] **No preaching:** No character gives "theme speech"

**METHODOLOGY:** Seger (Central Question), Truby (Moral Argument), McKee (Controlling Idea)

---

#### COMEDY-SPECIFIC (if applicable)

- [ ] **Comic premise clear:** Vorhaus formula (adjective + noun)
- [ ] **Comic flaw defined:** Protagonist's exaggerated trait (2x reality)
- [ ] **Comic opposition:** Flaw meets wrong environment
- [ ] **Escalation plan:** Each setpiece bigger than last
- [ ] **Comedy density plan:** No 10-minute stretches without laugh
- [ ] **Tone calibrated:** Dark comedy vs. light comedy clearly defined

**METHODOLOGY:** Vorhaus (Comic Tools), Blake (Comedy Structure), Sacks (Benign Violation)

---

### 5.2 Mid-Draft Checkpoint

**USE AT PAGE 60: Course-correct before completing draft**

#### STRUCTURE CHECK (at midpoint)

- [ ] **Catalyst occurred:** Pages 10-15, clear and physical
- [ ] **Plot Point 1 clear:** Commitment occurred pages 25-30
- [ ] **Midpoint reached:** Major event at page 50-60 that reframes story
- [ ] **Act I established:** World, rules, tone clear
- [ ] **Protagonist goal clear:** Stated explicitly somewhere in Act I
- [ ] **Opponent introduced:** Antagonist or obstacle established
- [ ] **Stakes escalating:** Each sequence harder than previous

**IF 2+ UNCHECKED:** Stop drafting, fix structure before continuing

---

#### CHARACTER CHECK

- [ ] **Protagonist active:** Driving story, not reacting
- [ ] **Goal maintained:** Still pursuing same objective (or consciously changed)
- [ ] **Flaw causing problems:** Failures result from character flaw
- [ ] **Vulnerability shown:** Audience relates to protagonist
- [ ] **Opponent credible:** Poses real threat, winning some battles
- [ ] **Supporting characters present:** Haven't disappeared for 20+ pages
- [ ] **Relationships developing:** Connections between characters evolving

**IF 2+ UNCHECKED:** Strengthen character work in next 30 pages

---

#### SCENE-LEVEL CHECK (sample every 10 pages)

- [ ] **Scenes have conflict:** Characters want incompatible things
- [ ] **Scenes turn:** Emotional values shift by scene end
- [ ] **Scenes connect:** Each disaster creates next goal
- [ ] **Scene length appropriate:** Most 2-3 pages
- [ ] **Enter late/exit early:** Trimmed of fat

**IF 2+ UNCHECKED:** Tighten scene work going forward

---

#### MOMENTUM CHECK

- [ ] **Reading fast:** Pages turning quickly
- [ ] **Emotional engagement:** Scenes feel involving
- [ ] **Curiosity:** Want to know what happens next
- [ ] **No boredom zones:** No pages where interest flags

**IF ANY UNCHECKED:** Identify problem area and address before continuing

---

#### COMEDY CHECK (if applicable)

- [ ] **Consistent laughs:** Funny moments every 3-5 pages
- [ ] **Premise delivering:** Comic promise being fulfilled
- [ ] **Escalating:** Setpieces getting bigger
- [ ] **Character-based:** Humor comes from flaw, not random jokes

**IF 2+ UNCHECKED:** Strengthen comedy in second half

**CRITICAL (1-2 scores):** Address immediately in Pass 1
**MAJOR (3 scores):** Address in Pass 2
**MINOR (4 scores):** Polish in Pass 3+

- Focus: Act breaks, turning points, causality, pacing

- Duration: 2-3 weeks

- Duration: 1-2 weeks

### 5.4 Polish Checklist

**USE BEFORE SUBMITTING: Final quality control**

#### FORMAT & PRESENTATION

- [ ] **Proper screenplay format:** Industry-standard throughout
- [ ] **Consistent character names:** Same spelling/format every time
- [ ] **Consistent location names:** No variations
- [ ] **Page appearance:** White space, readable, not dense
- [ ] **Action lines:** Clear, concise, present tense
- [ ] **Parentheticals:** Minimal (only when essential)
- [ ] **Spell-check:** No typos
- [ ] **Grammar:** Correct throughout
- [ ] **Page count appropriate:** 90-120 pages (feature), proper length (TV)

---

#### SCENE-LEVEL POLISH

- [ ] **Slug lines correct:** INT./EXT., location, time of day
- [ ] **Scene transitions appropriate:** CUT TO, FADE TO, etc. used correctly
- [ ] **Action paragraphs:** 3-4 lines maximum (break up longer blocks)
- [ ] **Character introductions:** All caps first appearance, age included
- [ ] **Visual clarity:** Can visualize each scene
- [ ] **Sound clarity:** Can "hear" dialogue

---

#### DIALOGUE POLISH

- [ ] **Character names:** Centered above dialogue
- [ ] **Dialogue blocks:** Not too long (break up speeches)
- [ ] **Contractions:** Used naturally
- [ ] **Read-aloud test:** Sounds natural when spoken
- [ ] **Overlaps/interrupts:** Marked appropriately (if used)
- [ ] **Foreign language:** Handled clearly

---

#### STORY CONSISTENCY

- [ ] **Timeline coherent:** Days/weeks/months track
- [ ] **Character ages consistent:** Don't fluctuate
- [ ] **Locations consistent:** Same place described same way
- [ ] **Props tracked:** Items that appear/disappear make sense
- [ ] **Character knowledge:** Know what they should know when
- [ ] **Weather/seasons:** Consistent unless time passes

---

#### PROFESSIONAL PRESENTATION

- [ ] **Title page:** Proper format (no pictures, correct info)
- [ ] **Page numbers:** Bottom right, "CONTINUED" where appropriate
- [ ] **No directing:** No camera angles unless essential
- [ ] **No budget notes:** No "this is cheap to shoot"
- [ ] **Show confidence:** No apologies, hedging, or self-deprecation

---

#### FINAL READ

- [ ] **Read aloud once:** Catches rhythm problems
- [ ] **Fresh eyes:** Someone else reads if possible
- [ ] **Time buffer:** Don't submit last-minute
- [ ] **Backup saved:** Multiple copies in different locations
- [ ] **PDF created:** Send as PDF (protects format)
