D.1 PARADIGM IDENTIFICATION

Paradigm	Description	Historical Root	Randazzo’s Transformation
Classic Mimetic	Comedy imitates life to correct social folly.	Aristotle → Horace	Retains corrective aim but adds self-parody; the “mirror” laughs back.
Romantic Sublime	Humor as release from repression; laughter restores vitality.	Freud → Bergson	Reframes “release” as feedback: tension = hypothesis, laugh = confirmation.
Modern Irony	Cynicism as sophistication; laughter as defense.	Baudelaire → Postmodernism	Replaces irony with ethical sincerity—humor reconnects rather than distances.
Metamodern Humor	Oscillation between irony and sincerity.	Late 2000s web culture	Core of Randazzo’s paradigm: “laughing at and with” the world simultaneously.

	•	Implication: The joke is a microcosm of human resilience.

2️⃣ Epistemological Position

	•	Knowledge is true when it feels funny because it surprises without annihilating sense.
	•	Truth = coherence under disruption.
→ #embodied-cognition #affective-epistemology

3️⃣ Axiological Dimension (Values Embedded)

Comedy enacts ethical intelligence—the value of perspective-switching.

→ #axiology-of-humor #moral-cartography

Randazzo’s pedagogy privileges experimentation over prescription:
	•	Write → perform → analyze → rewrite.

Violation	Punchline	Error detected
Resolution	Laughter	Model updated
Reinforcement	Callback	Learning consolidated

Thus, laughter is the neural applause for cognitive recalibration.
→ #predictive-processing #reward-learning

2️⃣ Emotional Calibration

Comedy trains emotional elasticity—switching from tension to delight in milliseconds.
	•	Biochemical reward: dopamine + endorphins during recognition.
	•	Behavioral function: builds tolerance for ambiguity.
→ #affective-regulation #emotional-flexibility

3️⃣ Social Cognition

Humor increases empathic accuracy by forcing perspective reversals.
	•	Every joke = a thought experiment in theory of mind.
→ #social-neuroscience #empathy-training
