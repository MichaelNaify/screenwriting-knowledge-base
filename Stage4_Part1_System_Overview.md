## §0 | ARCHITECTURE OVERVIEW

### §0.1 | The Complete Knowledge Cycle

Stage 4 completes the circular knowledge architecture by establishing measurement systems and evolution protocols. The five-stage system works as:

```
┌──────────────────────────────────────────────────────────────┐
│                     KNOWLEDGE ARCHITECTURE                    │
│                                                               │
│  Stage 0: "What exists?"         → Master Concept Ontology   │
│  Stage 1: "What does X mean?"    → Deep Analysis             │
│  Stage 2: "How do concepts relate?" → Synthesis              │
│  Stage 3: "How do I use this?"   → Implementation            │
│  Stage 4: "How do I measure & evolve?" → Evaluation          │
│           ↓                                 ↑                 │
│           └─────────────────────────────────┘                │
│              (Continuous Feedback Loop)                       │
└──────────────────────────────────────────────────────────────┘
```

**Core Principle:** Stage 4 transforms static knowledge into a living, self-improving system by:
1. Measuring effectiveness of Stages 0-3 applications
2. Assessing quality of creative outputs
3. Tracking learning progress and skill acquisition
4. Benchmarking against professional standards
5. Identifying system improvements
6. Feeding insights back to update earlier stages

## §2 | EVALUATION PHILOSOPHY

### §2.1 | Core Assessment Principles

**1. Evidence-Based Measurement**
- Every criterion grounded in Stage 0-3 documented principles
- Every score requires specific textual/behavioral evidence
- Every feedback point cites source methodology
- NO assessment based on subjective impression alone

**2. Developmental Appropriateness**
- Beginner work assessed against beginner standards
- Professional work assessed against industry standards
- Context matters: student script vs. sale-ready screenplay
- Growth trajectory valued alongside absolute achievement

**3. Integration Emphasis**
- Single-source application (using only McKee) assessed differently than integrated approach
- Integration quality measured as distinct dimension
- Synthesis effectiveness tracked across all evaluations
- Stage 2 integration guidance referenced in assessment

**4. Actionable Feedback Priority**
- Every weakness identified must include improvement path
- Every score paired with specific revision recommendations
- Every assessment routes to Stage 3 implementation tools
- Diagnosis always paired with prescription

**5. Balanced Quantitative-Qualitative Approach**
- Numerical scores provide consistency and tracking
- Qualitative analysis captures nuance and context
- Both required for complete assessment
- Neither sufficient alone

## §4 | QUALITY STANDARDS & ANTI-HALLUCINATION

### §4.1 | Assessment Validity Requirements

**Every assessment criterion MUST:**

1. **Cite Source Grounding**
   - Reference specific Stage 0-3 concepts
   - Include page numbers when citing source texts
   - Link to relevant Stage documentation

2. **Define Operational Measurement**
   - Specify what evidence demonstrates achievement
   - Provide concrete examples of criterion met/not met
   - Include scoring guidelines with clear thresholds

3. **Support Actionable Feedback**
   - Link to Stage 3 improvement protocols
   - Identify specific exercises or techniques
   - Provide revision roadmap for deficiencies

4. **Enable Consistent Application**
   - Reduce evaluator subjectivity through precision
   - Provide calibration examples
   - Support inter-rater reliability

**FORBIDDEN:** Assessment criteria based on:
- Pure subjective impression without grounding
- Unstated personal preferences
- Industry trends not documented in system
- Concepts not present in Stage 0-3
- Standards without operational definitions
