1.3 S-AIT — Act Integrity Test (#act-ledger)

Purpose

Ensure each act performs its structural and emotional duty: setup → development → resolution.

Inputs
	•	Beat map (JSON)
	•	Act boundary indices
	•	Value shift table

Procedure
	1.	Load beats by act.
	2.	Calculate Δ value continuity per act.
	3.	Run Energy Slope test (should rise to climax).
	4.	Audit turning-point density (≥ 2 per act).
	5.	Cross-check theme presence via keyword match.

Metrics

Indicator	Target	Action
Δ Energy Slope	+0.03–0.05	OK
Turning Points	≥ 2 per act	else insert decision beat
Theme Presence	≥ 0.8 correlation	else embed reinforcing subplot

Deliverable

ActIntegrityLedger.yaml → includes energy curves & theme tags.

Failures → Fixes
	•	Flat slope → raise stakes or accelerate tempo.
	•	Missing reversal → insert value flip scene.
	•	Tone drift → align transition beats.

⸻

1.4 S-SPT — Scene Purpose Triad (#scene-intent)

Purpose

Test every scene for its dramatic function: purpose → conflict → change.

Procedure
	1.	Ask Seger’s three questions: Who drives it? What changes? Why now?
	2.	Mark value shift (+/–).
	3.	Rate conflict amplitude (0–1).
	4.	Assess thematic echo (0–1).
	5.	Compute Scene Purpose Index (SPI): mean of three.

Pass Condition → SPI ≥ 0.8.

If below 0.8, rewrite or merge.

Deliverable

SceneIntentSheet.csv tagged #scene-audit.

⸻

1.5 S-SPS — Sequence Purpose Sheet (#sequence-ledger)

Purpose

Maintain momentum and cause–effect logic across connected scenes.

Procedure
	1.	Group scenes by goal.
	2.	Label emotional throughline.
	3.	Measure beat density (ideal σ ≥ 0.3).
	4.	Plot Sequence Pulse Curve.
	5.	Check for logical hand-off (next sequence trigger ≥ 0.85 continuity).

Output

SequenceBeatLedger.md with auto-graph.

Failure → Fix
	•	Drop in continuity → insert bridge beat.
	•	Redundant goal → merge sequence.
