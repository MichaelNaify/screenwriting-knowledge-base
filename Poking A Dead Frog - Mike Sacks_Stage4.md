§0 PURPOSE OF CHUNK B — THE BEAT ECONOMY (#beat-lab-purpose)

Comedy lives and dies on timing.

§1  FOUNDATIONS OF TEMPORAL DESIGN (#temporal-foundations)

1.1  The Beat as Unit of Meaning (#beat-definition)

Definition:
A beat = the smallest measurable exchange of intention that alters audience expectation.

Each beat has four temporal coordinates:
t0 = setup start, t1 = expectation formed, t2 = disruption, t3 = resolution.
Average beat length in sitcom flow ≈ 4–6 seconds S3:#beat-economy.

⸻

1.2  Beat Compression Law (#compression-curve)

Let
Δt = t3 – t0 (beat duration).
When consecutive beats overlap ≥ 40 %, cognitive tension rises until release → laughter amplitude ↑ 15 – 20 %.
Over-compression (< 3 s) → perceptual saturation → audience fatigue.
Optimal window: 3.5 – 6.2 s per beat.

if Δt < 3.0: flag("timing overspeed")
if Δt > 7.0: flag("drag risk")


⸻

1.3  Silence Windows (#negative-space)

Silence = the breath between beats.
Target silence window ( sw ) =  0.3 × Δt.
Thus, for a 5 s beat, ideal silence ≈ 1.5 s.
Below 0.5 s → audience cannot register; above 3 s → energy collapses.

Silence functions as empathy buffer: laughter ends → reflection begins.

⸻

§2  THE LAUGH-DENSITY ENGINE (#lpm-system)

2.1  LPM Metric (#laughs-per-minute)

Formula: LPM = (total laughs × 60) / runtime (sec)
Target ranges per format:

Medium	Optimal LPM	Texture
Late-night monologue	6 – 8	Rapid rhythm
Multi-cam sitcom	4 – 6	Shared beats
Single-cam comedy-drama	2 – 3	Emotional humor
Feature film	1.5 – 2.5	Story-driven
Sketch (2 min)	5 – 7	High voltage

Procedure: tag each audible laugh in recorded table read; compute moving average over 30 s windows.
Auto-plot as LPM curve → detect flatlines > 20 s = rewrite zone.

⸻

2.2  LPM Δ – Rate of Decay (#timing-consistency)

Between scene A and scene B,
ΔLPM = LPM_B – LPM_A.
Healthy range: −0.5 ≤ Δ ≤ +0.5.

If Δ < −0.8 → audience fatigue.
If Δ > +0.8 → pacing whiplash.
Recalibrate by modulating silence windows and callback density.

⸻

§3  CALLBACK ARCHITECTURE AND RESONANCE MAPS (#callback-system)

3.1  Definition

A callback is a second-order beat that references a previous joke to create recognition and cohesion.

Variables:
	•	origin_id = initial beat
	•	callback_id = recurrent beat
	•	ΔT = time difference
	•	r = resonance index = laughter amp(callback) / amp(origin)`

Ideal r ∈ [0.7, 1.3]. Below 0.5 = forgotten callback; above 1.5 = forced echo.

⸻

3.2  Callback Matrix Template

origin_id,callback_id,ΔT(sec),amp_origin,amp_callback,resonance_index,note

5B,5E,240,0.9,0.4,0.44,"lost connection – rewrite"

Visualize matrix as diagonal heatmap: brighter = stronger resonance.

⸻

3.3  Resonance Density Index (RDI)

RDI = callbacks / total beats
Target RDI: 0.25 – 0.40.
Too low → fragmented story; too high → self-referential loop.
Boot Camp benchmark: one callback every 25 – 35 lines.
