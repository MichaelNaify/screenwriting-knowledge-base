A.2 McKee’s Dialogue System Architecture (#system-architecture) #mckee #verbal-action #micro-causality

Foundation: McKee situates Dialogue as the micro-mechanics that complete Story’s macro-mechanics—macro causality (structure) plus micro causality (speech in conflict)【turn0file5†Dialogue - Robert McKee_Stage1.md†L11-L15】. Dialogue is performative behavior (not descriptive ornament): it enacts intention under pressure, generating beat-to-beat change【turn0file13†Dialogue - Robert McKee_Stage1.md†L55-L67】【turn0file3†Dialogue - Robert McKee_Stage2.md†L1-L5】.

A.2.1 Core elements (from Stage 1/2) (#core-elements)
	•	Verbal Action: Intention + Obstacle + Tactic → Verbal Action【turn0file13†Dialogue - Robert McKee_Stage1.md†L60-L67】.
	•	Three tracks of talk: to others, to self, to audience/reader; each remains intentional action【turn0file0†Dialogue - Robert McKee_Stage2.md†L39-L43】.
	•	Dramatized vs. Narratized delivery (in-scene conflict vs. audience-directed talk/VO/inner speech)【turn0file3†Dialogue - Robert McKee_Stage2.md†L1-L3】.
	•	Beat Physics: dialogue drives action→reaction and topping toward a turning point【turn0file3†Dialogue - Robert McKee_Stage2.md†L5-L12】.
	•	Exposition Doctrine: weaponize information (timing + conflict)【turn0file14†Dialogue - Robert McKee_Stage2.md†L20-L23】.
	•	Idiolect/Voice: design vocabulary, syntax, rhythm as identity markers【turn0file2†Dialogue - Robert McKee_Stage1.md†L44-L48】.
	•	Medium Sensitivity: stage/screen/prose impose different dialogue loads and rhythms【turn0file7†Dialogue - Robert McKee_Stage2.md†L11-L14】.

A.4 Master Diagnostic Protocol (#master-diagnostic) #diagnostic-tool #triage #checklist

[DIAGNOSTIC SYSTEM] The Dialogue Health Assessment™ consolidates Stage-1 method categories and Stage-2 structures into a single, timed protocol. All questions derive from McKee’s principles listed in A.2–A.3; the sequencing and scoring below are our application layer【turn0file2†Dialogue - Robert McKee_Stage1.md†L27-L41】【turn0file11†Dialogue - Robert McKee_Stage2.md†L9-L13】.

A.4.1 Scope & timing (#scope-timing)
	•	Per scene: 12–20 minutes
	•	Per sequence (3–5 scenes): 60–90 minutes
	•	Per feature draft: 1.5–3 days (dialogue-only pass)

A.4.2 Scene-by-scene evaluation checklist (#scene-checklist)

Run in order. If a step fails, apply its fix and re-test before proceeding.

Step 1 — Scene purpose & value
	•	Identify declared value change targeted by the scene (Story link)【turn0file8†Story - Robert McKee_Stage2.md†L27-L33】.
	•	If missing: define protagonist’s scene objective and design an opposition that can flip or charge the value (#scene-purpose).
	•	Output: one-line Value Intent Statement (VIS).
	•	Example: “From trust to doubt as A confronts B about the missing funds.” #value-statement

Step 2 — Beat map (action→reaction→top→turn)
	•	Mark beats as gerunds (insulting, deflecting, baiting) (McKee’s beat focus)【turn0file3†Dialogue - Robert McKee_Stage2.md†L13-L18】.
	•	Ensure topping toward a turn【turn0file3†Dialogue - Robert McKee_Stage2.md†L9-L12】.
	•	If flat: add power reversals every 1–3 beats (#power-shift).

Step 3 — Subtext source check
	•	For each beat, ask: What pressure is unsaid? (Stage-1 subtext primacy)【turn0file2†Dialogue - Robert McKee_Stage1.md†L11-L16】【turn0file9†Dialogue - Robert McKee_Stage1.md†L7-L10】.
	•	If on-the-nose: insert contradiction/silence/deflection (see A.6 table). #subtext-design

Step 4 — Exposition audit
	•	Flag any facts delivered. Require conflict context and consequence (exposition-as-ammunition)【turn0file14†Dialogue - Robert McKee_Stage2.md†L20-L23】.
	•	If inert: move fact to a turning beat or re-weaponize as a tactic. #exposition-in-conflict

Step 5 — Voice differentiation
	•	Single out lexicon/syntax/rhythm per character (idiolect design)【turn0file2†Dialogue - Robert McKee_Stage1.md†L44-L48】.
	•	If voices blur: run CVD test in metrics (A.5). #voice-pass

Step 6 — Line-level function
	•	Apply Three-Function Test™ (plot/character/relationship) grounded in McKee’s function triad【turn0file11†Dialogue - Robert McKee_Stage2.md†L9-L13】.
	•	Triple-fail lines → delete; single/double fail → fix using subtext or tactic swap. #three-function-test

Step 7 — Performability
	•	Read aloud; confirm the line invites acting choices (tone options, gesture completion)【turn0file12†Dialogue - Robert McKee_Stage2.md†L7-L13】【turn0file12†Dialogue - Robert McKee_Stage2.md†L47-L55】.
	•	If flat: re-meter punctuation/whitespace; add conflict-driven interruptions【turn0file4†Dialogue - Robert McKee_Stage2.md†L43-L51】. #performability

A.4.3 Problem identification matrix (#problem-matrix)

Map observed symptoms to likely causes and fixes.

Symptom	Likely Cause (McKee)	Primary Fix
Flat scene (no build)	Missing beat topping / soft opposition【turn0file3†Dialogue - Robert McKee_Stage2.md†L9-L12】	Insert power reversals; escalate tactics
“On-the-nose” lines	Subtext not engineered【turn0file2†Dialogue - Robert McKee_Stage1.md†L41-L47】	Add contradiction/silence/deflection
Info-dump	Exposition outside conflict【turn0file14†Dialogue - Robert McKee_Stage2.md†L20-L23】	Weaponize fact at turn; shift timing
Voices sound alike	Idiolect not defined【turn0file2†Dialogue - Robert McKee_Stage1.md†L44-L48】	Build lexicon/syntax rhythms per character
Lines don’t land in performance	No actor choice invited【turn0file12†Dialogue - Robert McKee_Stage2.md†L7-L13】	Re-meter, punctuate, embed conflict cues

A.4.4 Priority ranking system (#priority-ranking)
	1.	Scene purpose/value (no purpose → nothing matters).
	2.	Beat dynamics (no topping → stasis).
	3.	Subtext & exposition integration (energy source + information flow).
	4.	Voice (identity) → Line function (efficiency) → Performability (deliverability).

A.5 Metrics & Measurement Systems (#metrics) #quant #scores #triage

[APPLICATION] The following metrics quantify McKee’s principles so you can triage pages, compare drafts, and set genre-appropriate targets. Each metric’s idea is grounded in Stage 1/2; the arithmetics are our applied layer.

A.5.1 Dialogue Density Index (DDI) (#ddi)

Purpose: Track how much dialogue carries functional weight relative to scene length.
Basis: McKee’s economy and beat micro-causality—lines must do work【turn0file3†Dialogue - Robert McKee_Stage2.md†L5-L12】.
Formula:
DDI = (Functional Lines ÷ Total Lines) × 100
Functional Line = passes ≥1 function (plot/character/relationship) per A.4 Step 6【turn0file11†Dialogue - Robert McKee_Stage2.md†L9-L13】.
Targets:
	•	Drama 75–90 | Thriller 70–85 | Comedy 60–80 | Action 45–65.
Use: Low DDI → run Three-Function Test™ fixes.

A.5.2 Subtext Ratio (SR) (#sr)

Purpose: Ensure meaning ≠ words.
Basis: Subtext primacy in Stage-1; implicature mapping in Stage-2【turn0file2†Dialogue - Robert McKee_Stage1.md†L11-L16】【turn0file4†Dialogue - Robert McKee_Stage2.md†L15-L23】.
Formula:
SR = (Lines with deliberate A≠B gap ÷ Total Lines) × 100
Targets:
	•	Thriller 80–90 | Drama 70–80 | Comedy 40–60 | Action 20–40.
Test: Can an actor play two levels (text vs. intent)? If no → add contradiction, evasion, silence【turn0file4†Dialogue - Robert McKee_Stage2.md†L15-L23】【turn0file12†Dialogue - Robert McKee_Stage2.md†L1-L4】.

A.5.3 Functional Efficiency Score (FES) (#fes)

Purpose: Average number of functions served per line.
Basis: McKee’s function triad; cut lines that don’t do enough【turn0file11†Dialogue - Robert McKee_Stage2.md†L9-L13】.
Formula:
FES = (Total Passed Functions across all lines ÷ Total Lines)
Targets: Drama 2.5–3.0 | Thriller 2.0–2.5 | Comedy 1.5–2.0 | Action 1.0–1.5.
Use: Raise via tactic swaps and subtext additions.

A.5.4 Character Voice Differentiation (CVD) (#cvd)

Purpose: Detect voice blend.
Basis: Stage-1 idiolect design; Stage-2 performability cues【turn0file2†Dialogue - Robert McKee_Stage1.md†L44-L48】【turn0file12†Dialogue - Robert McKee_Stage2.md†L36-L44】.
Method: Blind a page; assign lines to characters.
Score: CVD = (% of lines correctly assigned by a cold reader).
Targets: ≥85% for drama/thriller; ≥75% comedy/action.
If low: rebuild lexicon/syntax rhythms per character; add status-linked sentence length cues【turn0file4†Dialogue - Robert McKee_Stage2.md†L43-L51】.

A.5.5 Beat Kinetics Index (BKI) (#bki)

Purpose: Measure topping pressure.
Basis: action→reaction + escalation to turn【turn0file3†Dialogue - Robert McKee_Stage2.md†L5-L12】.
Method: Count beats; count reversals or intensifications.
Formula: BKI = (Intensifying Beats ÷ Total Beats) × 100.
Targets: 50–70% intensifying beats for most drama/thriller scenes.
Fix: Add verbal power reversals (A.4 Step 2).

A.5.6 Exposition in Conflict Index (ECI) (#eci)

Purpose: Ensure facts arrive as ammunition.
Basis: McKee’s exposition doctrine【turn0file14†Dialogue - Robert McKee_Stage2.md†L20-L23】.
Formula: ECI = (Expository beats delivered under explicit opposition ÷ Total expository beats) × 100.
Target: ≥90% for drama/thriller; ≥80% comedy; ≥70% action.
Fix: Re-time facts to moments of leverage or turn.

A.6 Quick Reference Guide (#quick-ref) #flowchart #fix-table #deadline

A.6.1 One-Page Diagnostic Flow (text form) (#flow)
	1.	Purpose? (VIS) → if none, define.
	2.	Beats escalate? → if no, add reversals.
	3.	Subtext present? → if no, add contradiction/evasion/silence.

	6.	Lines functional? → run Three-Function Test™.
	7.	Performable? → re-meter punctuation/whitespace.

B.1 The Scene Dialogue Protocol™ #scene-protocol #construction-framework

[DIAGNOSTIC + CONSTRUCTION FRAMEWORK: Built from Stage 1 sections on beat physics and verbal action; systematized here into a repeatable scene workflow.]

B.1.1 Overview

A scene is the fundamental dramatic unit in McKee’s system.  It turns a value through conflict.  Dialogue, as verbal action, becomes the mechanism that pressures that value until it flips.

B.1.2 Step-by-Step Protocol

STEP 1 – Define Scene Goal and Value Intent
	1.	Articulate the protagonist’s immediate intention (want).
	2.	Identify the opposing force.
	3.	Formulate the Value Intent Statement (VIS):
“From ___ to ___ as X confronts Y over ___.”
 (derived from A.4 VIS method in Part A).

STEP 2 – Map Beat Actions
	•	Write beats as active verbs (probing, baiting, cornering).
	•	Ensure causal linkage (each reaction tops the prior beat)【turn0file3†Dialogue – Robert McKee_Stage2.md†L5-L12】.
	•	Target 4–8 beats per average dialogue scene.

STEP 3 – Select Verbal Actions for Each Beat
	•	Draw from the Verbal Action Tactics Library (B.2).
	•	Every beat = one clear tactic aimed to overcome resistance.
	•	Mix tactic types to create texture (e.g., plead → threaten → mock).

STEP 4 – Embed Conflict and Subtext
	•	No line may state the scene’s theme directly.
	•	Pressure comes from what is not said【turn0file2†Dialogue – Robert McKee_Stage1.md†L41-L47】.
	•	When facts must surface, deliver them as weapons【turn0file14†Dialogue – Robert McKee_Stage2.md†L20-L23】.

STEP 5 – Topping and Turn
	•	At least one beat must reverse power or status (#power-shift).
	•	Final beat should turn the value (VIS achieved).

STEP 6 – Read Aloud and Test Performance
	•	Confirm each line offers an acting choice (tempo / tone / gesture)【turn0file12†Dialogue – Robert McKee_Stage2.md†L7-L13】.
	•	Cut or revise lines that produce no playable moment.

B.1.3 Completion Checklist (#checklist)

Criterion	Pass	Fix
Scene has clear Value Intent Statement		Define goal/opposition
Beats escalate (topping logic)		Add reversals
Each beat contains verbal tactic		Assign verbs
Exposition delivered through conflict		Weaponize info
Subtext present (unsaid pressure)		Insert contradiction/silence
Distinct voices		Apply CVD test
Turn completes value change		Revise ending beat

B.2 Verbal Action Tactics Library #verbal-action-tactics #writer-toolkit

[APPLICATION: Derived from McKee’s “verbal action” concept (Stage 1 §3.2); expanded into categorized tactics for scene design.]

B.2.1 Core Categories (6 Families)

Family	Definition	Example Tactics
Persuasive	Seek agreement or compliance	reason, flatter, bargain, appeal
Aggressive	Force change through pressure	threaten, insult, accuse, mock
Seductive	Entice or disarm	charm, tease, confide, promise
Deflective	Avoid or redirect	joke, question, digress, counter-ask
Revelatory	Expose truth/self	confess, admit, clarify
Strategic Silence	Withhold speech to gain power	pause, exit, look away

Use: Mix contradictory families within a scene to generate texture (e.g., persuasive → deflective → aggressive).

Common Mistake: repetition of the same tactic = flat beats.
Fix: switch tactic family every 1–2 beats or at each power reversal.

B.3 The Three-Function Test™ #three-function-test #diagnostic-system

Re-introduced here for scene-level operation (see A.4 Step 6 for line-level use).
Grounded in McKee’s function triad: exposition / character / action【turn0file11†Dialogue – Robert McKee_Stage2.md†L9-L13】.

B.3.1 Scene-Level Algorithm
	1.	List all lines in scene.
	2.	Mark ✓ for each function served:
 - Plot Advancement – changes situation or decision.
 - Character Revelation – shows want, fear, value.
 - Relationship Shift – alters power/intimacy/trust.
	3.	Compute FES (see A.5.3).
	4.	Revise lines failing ≥ 2 functions.
	5.	Triple-fail → delete (#economy).

Goal: ≥ 2 functions per line average for dramatic scenes.

B.3.2 Revision Protocol
	•	If Plot fails → add decision or consequence.
	•	If Character fails → embed subtext or tactic showing desire/fear.
	•	If Relationship fails → insert status change gesture or verbal shift.

B.4 Exposition Integration System #exposition-in-conflict #application

[APPLICATION FRAMEWORK based on McKee’s exposition-as-ammunition principle (Stage 1 §6.4; Stage 2 §4.3).]

B.4.1 Conflict-Exposition Matrix™

Conflict Level	Delivery Mode	Effectiveness	Usage Tip
0 – No Conflict	Monologue / VO	❌ Dead info	Convert to question/response
1 – Mild Resistance	Curiosity exchange	⚠️ Weak	Raise stakes via threat or need
2 – Active Opposition	Argument / interruption	✅ Strong	Tie fact to power loss/gain
3 – High-Risk Conflict	Revelation amid crisis	🏆 Optimal	Drop bomb at turning beat

B.4.2 Testing Procedure
	1.	Highlight every fact.
	2.	For each, mark Conflict Level (0–3).
	3.	Re-stage low-level facts as weapons or bargaining chips.
	4.	Retest using ECI metric (A.5.6) → target ≥ 90 %.

B.5 Scene Rhythm & Pacing #tempo #beats #energy-curve

Source Basis: Stage 2 discussion of dialogue as aural music and rhythmic energy【turn0file12†Dialogue – Robert McKee_Stage2.md†L43-L51】.

B.5.1 Tempo Variation Techniques
	•	Alternate beat lengths (short jabs vs extended runs).
	•	Insert micro-silences (ellipses, pauses).
	•	Vary syntax length per character status.
	•	Compress end beats toward turn for momentum.

B.5.2 Strategic Silence Placement
	•	Every 3–4 beats, allow a non-verbal reaction (#subtext).
	•	Silence = choice, not absence; scores as tactic in SR metric.

B.5.3 Energy Curve Management

Plot curve = value shift; dialogue curve = verbal pressure over time.
	•	Graph pressure (beat intensity 1–10).
	•	Ensure rising energy to turn, then drop or invert post-turn.

B.6 Mini Case — Applying Full Scene Protocol #case-study #hypothetical

[HYPOTHETICAL EXAMPLE for illustration.]

Scenario: A CEO fires her protege for leaking data.

VIS: Loyalty → Betrayal.

Beat verbs: accuse → deny → test → expose → dismiss → appeal → exit.

Before (weak)

CEO
You leaked the file.

PROTEGE
No, I didn’t.

CEO
We traced it to your account.

PROTEGE

After (protocol applied)

CEO
My inbox says you’re generous—with company secrets.

PROTEGE

CEO

PROTEGE

	•	Exposition as ammunition (level 3 conflict).
	•	Beat topping each exchange.
	•	Subtext (resentment, betrayal masked by irony).
	•	Distinct idiolects (CEO formal; protege sarcastic).
	•	Turn achieved at final beat (relationship rupture).

Metrics Snapshot: DDI 100 | SR 90 | FES 2.7 | CVD 95 | BKI 65 | ECI 100.

PART C — CHARACTER VOICE ARCHITECTURE

Purpose: Turn “voice” from an abstract ideal into a buildable, testable, rewritable system.
Foundation: McKee frames dialogue as verbal action, enacted through character-specific choices. Voice is not decoration; it’s the instrument that plays those actions.
This part delivers: a plug-and-play Voice Design System™, a hands-on Workshop, controls for Dialect & Register, a Voice Evolution Protocol across the story arc, and Ensemble Orchestration tools to prevent voice bleed.

⸻

C.1 Voice Design System™  #voice-design #framework

[APPLICATION FRAMEWORK: Implements McKee’s emphasis on intention, conflict, subtext, and identity markers into a repeatable voice-building workflow.]

C.1.1 Character Voice Profile (CVP) — Template

Create one CVP per speaking character before (or during) your first dialogue pass. Keep it to a single printable page.

IDENTITY
	•	Role in story: Protagonist / Antagonist / Ally / Foil / Gatekeeper (#integration)
	•	Core want right now vs. life want: __________________
	•	Wound / shame / status sensitivity: _________________

VOICE DIMENSIONS (the Seven)
	1.	Vocabulary Field — domains of words the character naturally uses (work, hobby, class, region).
	2.	Syntax Signature — how their sentences tend to arrange (fragmented / compound / clause-heavy / passive vs. active).
	3.	Rhythm & Tempo — average line length, breath units, interruption tolerance.
	4.	Register — formal ↔ informal; polite ↔ blunt; technical ↔ slang.
	5.	Figurative Habit — metaphor types (mechanical, culinary, legal, nautical), simile frequency, imagery palette.
	6.	Pragmatics — preferred tactics under pressure (deflect, joke, threaten, confess, bargain).
	7.	Silence Pattern — how and when they don’t speak (stonewall, slow burn, clipped assent).

PROHIBITED WORDS/CONSTRUCTIONS
	•	Items this character would never say (keeps voices from converging).
Example: “ain’t” banned for a meticulous barrister; Latinate abstractions banned for a blunt dockworker.

TELL-TALES (Identity Markers)
	•	3 lexical tells (e.g., “Right,” “Look—,” “For heaven’s sake”).
	•	2 syntactic tells (e.g., tag questions “…, isn’t it?”; parenthetical clauses).
	•	1 rhythmic tell (e.g., two-word punch line).

STRESS RESPONSE MAP
	•	Under low, medium, high pressure, how does voice change? (shortens? slips dialect? gets formal?)

AUDIT HOOKS
	•	A/B test lines: remove character names; can you assign speakers correctly? (Feeds CVD metric in §C.5.)

⸻

C.1.2 Voice Build — Five-Step Protocol
	1.	Seed the lexicon (10–20 words per character) drawn from background, job, obsessions.
	2.	Choose syntax (two rules you will keep 80% of the time).
	3.	Fix tempo (average line length & breath points).
	4.	Pick two go-to tactics under pressure (plus one “shadow” tactic they avoid until cracked).
	5.	Set two tells (one lexical, one rhythmic) to deploy sparingly (≤ once every 2–3 pages).

Time: 20–30 minutes per principal; 5–10 per secondary.

⸻

C.1.3 Voice Health Checks (use during drafting)
	•	Read-Down Test: read only this character’s lines in sequence; confirm a mini-arc of thought & tactic shifts.
	•	Cross-Fade Test: place two characters in alternating single lines; check contrast in lexicon/syntax/tempo.
	•	Gesture Sync: ensure lines invite playable action beats (gesture, look, timing), not just word info.

⸻

C.2 Voice Construction Workshop  #hands-on #exercises

Build muscle memory fast. Use these five exercises to generate and stress-test voice. Label with character name, save to a “Voice Lab” folder you can revisit during rewrites.

Exercise 1 — Vocabulary Fields

Goal: Fill the character’s natural word buckets.
	•	List 6 domains (Work, Family, Money, Body, Place, Time).
	•	For each: write 6–10 words they’d reach for first.
	•	Constraint: 60 seconds per domain—speed forces instinct.

Example (Detective, blue-collar):
Work: casefile, union, badge, overtime, precinct, paperwork
Money: tabs, rent, short, marker, overtime, pawn

Output: paste top 20 into CVP.

⸻

Exercise 2 — Syntax Signature

Goal: Fix a recognizable sentence shape.
	•	Pick one rule: fragments or clause chains or noun piles or question-heavy.
	•	Write 12 one-liners in that shape reacting to the same prompt (“You’re late”).
	•	Choose the 3 most “them” for your tell kit.

Example (Barrister, clause-heavy):
“While I applaud your dedication, the deadline, as stipulated, expired at noon.”

⸻

Exercise 3 — Rhythm & Tempo

Goal: Meter the breath.
	•	Write 8 lines: 2 words, 4 words, 8 words, 16 words, and reverse back down.
	•	Mark breath points (/, //).
	•	Read aloud for performability; adjust punctuation to score the rhythm.

⸻

Exercise 4 — Idiolect Development

Goal: Blend lexicon + syntax + rhythm into a living voice.
	•	Write a 10-line mini-scene of them ordering coffee.
	•	Force two tactic swaps mid-scene (e.g., flatter → threaten).
	•	Ensure subtext: what they want is not coffee.

⸻

Exercise 5 — Voice Stress-Test

Goal: Show how voice changes under pressure.
	•	Write 3 versions of the same confession at low, medium, high stakes.
	•	Track: Does dialect slip? Does tempo collapse? Does register spike formal?
	•	Lock results into Stress Response Map (CVP).

C.3 Dialect & Register Management  #dialect #register

[APPLICATION: Practical guardrails derived from principles of clarity, performability, and character consistency.]

C.3.1 When to Use Dialect
	•	Use dialect to mark power/identity contradictions, not to “sound local.”
	•	Rule of Readability: represent dialect with idiom and syntax, not heavy phonetic spelling. Keep audience flow first.
	•	Rule of Proportion: hint dialect in 1–2 anchor words per page, then let actor carry the rest.

C.3.2 How Much Dialect
	•	Principle: If dialect slows reading or blocks subtext, cut it by half.
	•	Page Budget: ≤ 10% of a character’s words may show dialect markers in any given scene.

C.3.3 Period & Class Registers
	•	Build a Register Ladder for each character (Ceremonial / Professional / Familial / Intimate).
	•	For each rung, pre-write 3 sample lines.
	•	During scenes, climb or descend the ladder to express power shifts (integration with scene dynamics).

C.3.4 Red Flags & Fixes
	•	Red Flag: “Tourist translation” (every colloquial spelled out).
Fix: swap to vocabulary choices (regional nouns/verbs) and syntax.
	•	Red Flag: All characters drift toward the same snarky meta-tone.
Fix: re-anchor register & syntax per CVP; ban that tone for two characters.

⸻

C.4 Voice Evolution Protocol  #arc #transformation

Voice evolves as pressure mounts. Treat it like a score you can write changes into.

C.4.1 Four-Phase Voice Arc (map across acts)
	1.	Establish — Clean, emblematic voice tells; predictable tactics.
	2.	Stress — Syntax shortens or tangles; tactic choice narrows or flips.
	3.	Fracture — Register slips; forbidden words emerge; silences lengthen.
	4.	Resolution/Transfiguration — A new balance: either mastery (chosen voice) or collapse (loss of voice).

C.4.2 Scene-Level Evolution Beats
	•	Identify three inflection scenes where voice visibly changes (e.g., midpoint crack, pre-climax exposure).
	•	Pre-design marker lines you’ll pay off (e.g., they finally say the word they’ve avoided).

C.4.3 Consistency vs. Evolution
	•	Rule: 70–80% consistency; 20–30% evolution.
	•	Use the Stress Response Map to keep change logical rather than arbitrary.

C.5 Multi-Character Ensemble Orchestration  #ensemble #orchestration

Prevent voice bleed. Compose a conversation like a piece of chamber music.

C.5.1 Voice Contrast Matrix

Build a 6×6 matrix for up to six principals:

Character	Lexicon	Syntax	Rhythm	Register	Tactics	Silence
A	legal/contract	clause chains	medium-long	formal	argue/define	stare
B	mechanical	fragments	short-staccato	blunt	mock/needle	walk-off
C	culinary	sensory lists	mid	warm	charm/confide	sip

(Complete for all.)

Check: no two columns should be identical; adjust until each column has at least two unique entries per character.

C.5.2 Conversation Choreography
	•	Entry Order: Bring in the highest-contrast voice second to prevent blending.
	•	Overlap: Allow overlap & interruption only where voices are maximally distinct (prevents mush).
	•	Hand-offs: Design tactic hand-offs (A needles → B charms → C adjudicates).

C.5.3 CVD Metric (Character Voice Differentiation)
	•	Test: Remove names; cold reader assigns lines to speakers.
	•	Target: ≥ 85% correct for drama/thriller; ≥ 75% comedy/action.
	•	If low: increase contrast in two dimensions (syntax + register, e.g.), and add one tell.

C.6.1 Differentiation Pass (Two Voices)

Context: Detective (A) vs. Art Dealer (B)

BEFORE (voice bleed)

A: We both know you took the painting. 
B: You don’t have proof. 
A: I don’t need proof to make your life hard. 
B: You won’t do anything.

AFTER (CVP applied)

A (fragments, cop lexicon)
That frame’s new. Pawn ticket still warm?

B (clause-heavy, genteel register)
Detective, if you intend to accuse me, do it without smudging my inventory.

A
I’ll smudge whatever leaks guilt.

B
Then do bring a cloth; you’re perspiring evidence.

Why it works:
	•	Lexicon split (pawn vs. genteel shop talk)
	•	Syntax split (fragments vs. clauses)
	•	Register contrast (blunt vs. polished)
	•	Tactics contrast (accuse/needle vs. parry/mock)

Context: Stoic father finally admits fear to adult child (Act III)

Marker set in Act I: Father avoids first-person pronouns; speaks in impersonal aphorisms.

Act III line (transfiguration):
“I was afraid you’d leave and I made that your problem.”
(First-person breach = growth; syntax simplifies; register softens.)

C.6.3 Dialect without Phonetics

Goal: Indicate Scottish cadence without heavy spelling.

	•	Use syntax tilt: fronted adverbs (“Right now I’ll no’ say”).
	•	Keep phonetics to a single anchor (“nae”) and let actor deliver the rest.

PART D — SUBTEXT CONSTRUCTION & ANALYSIS

Purpose: Teach writers to engineer subtext deliberately—building measurable gaps between text and intent that generate audience engagement.
Foundation: McKee defines dialogue as verbal action powered by subtext: the invisible pressure below the words that drives performance and emotional truth【turn0file2†Dialogue - Robert McKee_Stage1.md†L41-L47】【turn0file3†Dialogue - Robert McKee_Stage2.md†L13-L18】.
Goal: Convert the abstract “say one thing, mean another” into systematic design, diagnosis, and revision protocols.

D.1 Subtext Engineering System™  #subtext-engineering #diagnostic-system

[DIAGNOSTIC + APPLICATION SYSTEM derived from McKee’s emphasis on “verbal irony” and “conflict beneath speech” (Stage 1 §4.3, Stage 2 §§3.2–3.5).]

D.1.1 Core Formula — The Text-Subtext Gap

TEXT = what is spoken.
SUBTEXT = what is meant, wanted, feared, or concealed.
Gap = degree of contrast (semantic distance + emotional distance).

Formula:
TSG = (Degree of Contradiction + Degree of Concealment) ÷ 2

Genre Targets:
	•	Drama: 0.7–0.9
	•	Thriller: 0.8–0.95
	•	Comedy: 0.4–0.6
	•	Action: 0.2–0.4
	•	Romance: variable by stage (early 0.7 → climax 0.3)

(Values are [APPLICATION] metrics derived from genre averages in Stage 2 discussion of subtext density.)

⸻

D.1.2 Subtext Creation Workflow

STEP 1 — Identify Pressure Point
Locate the emotional or moral pressure that must remain unspoken (shame, desire, power, fear).
→ From McKee’s dictum: “The greater the pressure, the deeper the subtext.”【turn0file3†Dialogue - Robert McKee_Stage2.md†L13-L18】

STEP 2 — Choose Concealment Strategy
Select one of the six tools (§D.2).
Ask: “How does the character defend or disguise the truth?”

STEP 3 — Build Verbal Mask
Craft dialogue that satisfies a surface goal while hiding the underlying want.
	•	Replace direct statement with gesture, metaphor, or non sequitur.
	•	Introduce beat misalignment (listener answers different question).

STEP 4 — Calibrate Gap
Test each line with Text–Subtext Gap Calculator™:
	•	If gap < 0.3, meaning too explicit → add contradiction/deflection.
	•	If gap > 0.9, audience lost → insert small leak (gesture, phrase).

STEP 5 — Validate via Performance
Read aloud; ensure actor can play two simultaneous levels (surface + inner truth).
If only one playable level → revise for duality.

D.2 The Subtext Toolbox  #practical-tools

Six primary mechanisms, each with triggers, use cases, and sample lines.

Tool	Mechanism	Use When	Sample (HYPOTHETICAL)	Warning
1. Contradiction	Say opposite of truth	Need to hide vulnerability	“I couldn’t care less.” (Means: I’m devastated.)	Overuse flattens tone
2. Deflection	Change subject	Fear exposure	“Anyway, how’s your sister?”	Beware stalling; must shift power
3. Understatement	Minimize importance	Control emotion	“It’s just a scratch.”	Use sparingly; pair with behavior
4. Overstatement	Exaggerate to distract	Create misdirection	“I never loved you!”	Should invite doubt
5. Silence	Withhold response	Strategic power play	(Character exits instead of answering.)	Needs context; too frequent = void
6. Subject Change	Redirect focus	Manage threat	“That painting’s crooked.”	Best following confrontation

Integration:  Combine 2–3 tools within one exchange for multi-layer density.

D.3 Diagnostic Protocol for Weak Subtext  #diagnostic-tool

Symptoms:
	1.	Characters state feelings directly (“I’m angry with you”).
	2.	Every question receives a literal answer.
	3.	Lines summarize plot rather than drive conflict.
	4.	Scene lacks playable tension in read-alouds.

D.3.1 The “On-the-Nose” Test

Ask per line:

“Could an actor cut this line and the audience still infer it from behavior?”

	•	YES: cut or rewrite with subtext.
	•	NO: line earns its keep.

D.3.2 Five Revision Strategies

Issue	Revision Action
Literal statement	Replace with action-based line (“hand me the key”) expressing same emotion indirectly
Info speech	Shift fact into argument context
Emotional flatness	Add beat misalignment (answer doesn’t match question)
Lack of irony	Introduce contradiction (say opposite)
Repetition	Replace second statement with gesture or silence

D.4 Advanced Subtext Techniques  #advanced #multi-layer

D.4.1 Multi-Layer Subtext

Three stacked levels:
	1.	Text – what’s said.
	2.	Subtext – what’s meant.
	3.	Meta-Subtext – what the audience realizes beyond character awareness.

Example (HYPOTHETICAL)

POLITICIAN  
You’ve done a fine job burying the report.  

AIDE  
Not half as fine as you did writing it.

	•	Text: Praise.
	•	Subtext: Threat.
	•	Meta: Audience sees corruption both accept.

D.4.2 Dramatic Irony via Dialogue

Give the audience privileged knowledge the character lacks; use dialogue to create tension between awareness levels.
	•	Technique: plant double meanings (“You’ll be safe here” when audience knows danger).
	•	Measure: maintain irony ≤ 20% of runtime to avoid fatigue.

D.4.3 Self-Deception

Character uses dialogue to mislead themselves.
	•	Detectable when subtext and inner need (from Part C CVP) diverge.
	•	Add visible cracks: stammer, filler, forced humor.

D.4.4 Subtext through Rhythm and Syntax
	•	Long sentences = control; fragments = leak.
	•	Use punctuation (— … ,) to reveal hesitation.
	•	Shortening syntax across beats = pressure increase.

E.1 The Five-Pass Dialogue Revision System™  #five-pass-system #diagnostic-system

[APPLICATION FRAMEWORK built from McKee’s “functional efficiency” and “rewriting as discipline” principles (Stage 1 §3.5; Stage 2 §4.6).]

E.1.1 Overview

Each pass isolates one axis of improvement. Never combine passes; separate focus yields higher precision.

Pass	Purpose	Metric	Output
1. Functional Efficiency	Ensure every line serves story	FES (A.5.3)	Lines that earn place
2. Voice Consistency	Maintain idiolect integrity	CVD (C.5.3)	Distinct speakers
3. Subtext Depth	Conceal/reveal effectively	SR (A.5.2)	Layered meaning
4. Rhythm & Music	Tune tempo, pacing	BKI (A.5.5)	Playable energy
5. Economy & Precision	Cut redundancy	DDI (A.5.1)	Tight, filmable pages

Total Time: 1–2 hours per 5-page scene; 2–4 days for feature draft.

⸻

PASS 1 — Functional Efficiency (#pass1)

Question: Does every line do something?
Procedure:
	1.	Apply Three-Function Test™ (B.3).
	2.	Score lines (0–3 functions).
	3.	Delete all triple-fails; rewrite single-fail.
	4.	Re-compute FES → target ≥2.0 (drama).
Common Fix: Add plot consequence, subtext action, or power shift.

⸻

PASS 2 — Voice Consistency (#pass2)

Question: Does each line sound like its speaker?
Procedure:
	1.	Isolate each character’s dialogue.
	2.	Cross-check against CVP (C.1).
	3.	Repair register/lexicon drift.
	4.	Run CVD blind test (C.5.3).
Target: ≥85 % correct assignment for principal characters.

⸻

PASS 3 — Subtext Depth (#pass3)

Question: Does the line carry dual meaning?
Procedure:
	1.	Measure SR (A.5.2).
	2.	Apply Toolbox (D.2): contradiction/deflection/etc.
	3.	Mark leak points pre-climax.
Target: Genre-appropriate SR band (Drama 70-80 %, Thriller 80-90 %, etc.).

⸻

PASS 4 — Rhythm & Music (#pass4)

Question: Does it play like music?
Procedure:
	1.	Read aloud; mark breath units (/ //).
	2.	Adjust punctuation, sentence length, silence beats.
	3.	Ensure BKI ≥ 50 % (half beats intensify).
Tip: Alternate 1-line exchanges with 3-line builds for pulse contrast.

⸻

PASS 5 — Economy & Precision (#pass5)

Question: Can it be shorter?
Procedure:
	1.	Run Dialogue Cut Protocol™ (E.3).
	2.	Apply 10 % reduction rule: cut 1 line / page minimum.
	3.	Verify DDI ≥ 70 % (drama baseline).
Heuristic: If meaning survives after cut → keep cut.

E.3 Dialogue Cut Protocol™  #cut-protocol #economy

[APPLICATION derived from McKee’s insistence that “the cut is the writer’s ultimate act of power.” (Stage 1 §5.4 paraphrase).]

E.3.1 When to Cut

Test	Keep	Cut
Advances story?	✅	❌
Reveals character?	✅	❌
Alters relationship?	✅	❌
Redundant with action?	❌	✅
Exists only for realism?	❌	✅

Triple-fail → delete immediately.

E.3.2 Compression Techniques
	•	Trilogy Cut: merge 3 similar lines into 1 pivot line.
	•	Echo Cut: keep first emotional beat, cut repetition.
	•	Beat Swap: turn statement → question to shorten.
	•	Action Substitution: replace talk with gesture.

E.3.3 Strategic Silence vs. Speech
	•	Replace one expositional paragraph per scene with visual action (Stage 2 §6.3).
	•	Use pause punctuation (— … ) to imply thought rather than spelling it out.

E.4 Line-Level Surgical Revision  #line-surgery

Purpose: refine micro-mechanics after macro passes.

E.4.1 Word Choice Optimization
	•	Favor active verbs, specific nouns; avoid adjectives as emotion markers.
	•	Replace “I feel…” with behavioral equivalent (“I can’t breathe in here”).

E.4.2 Syntax Variation for Effect
	•	Power = brevity; vulnerability = run-on.
	•	Split long clauses for rhythm.

E.4.3 Strategic Interruptions
	•	Add em-dash or ellipsis to simulate thought collision; maintain realism.
	•	Use cross-talk for rising tension (actors overlap lines).

E.4.4 Punctuation for Rhythm
	•	Comma = inhale; period = stop; dash = surge; ellipsis = fade.
	•	Mark performer breaths for BKI tuning.

E.4.5 Parenthetical Usage (sparingly)
	•	Only to clarify subtext shift (e.g., “(smiling, lying)”).
	•	Max 1 per 10 lines; delete if actor can infer.

E.5 Read-Aloud Testing Protocol  #performance-testing

McKee emphasizes performability—dialogue must invite actor choice【turn0file12†Dialogue - Robert McKee_Stage2.md†L7-L13】.

E.5.1 Setup
	•	Gather 2–3 readers (actors or peers).
	•	Provide printed scripts; mark pauses, overlaps.
	•	Time each scene; compare pacing to intended runtime.

E.5.2 What to Listen For

Signal	Meaning	Action
Flat delivery	Rhythm problem	Shorten lines / add tempo contrast
Confusion	Missing subtext cues	Insert leaks / clarify stakes
Monotone	No power shifts	Re-map tactics
Actor adds gesture	Good!	Integrate as stage direction

E.5.3 Revision Loop
	1.	Record session.
	2.	Annotate script with timestamped notes.
	3.	Run Pass 4 (Rhythm) and Pass 5 (Economy) based on playback.
	4.	Repeat until actors no longer ad-lib clarifying lines.

G.1 Dialogue Across the Three-Act Structure  #three-act-structure #macro-integration

G.1.1 Overview

McKee’s Story model defines three acts of value movement: setup → confrontation → resolution. Dialogue supplies the verbal pressure mechanics that make those turns believable.

⸻

ACT I — Establishment (#act1)

Function	Dialogue Role
Exposition	Reveal through conflict (not explanation)【turn0file14†Dialogue - Robert McKee_Stage2.md†L20-L23】
Characterization	Fix idiolect and tactics (see Part C)
Tone & Genre	Define subtext density baseline (see Part F)
Theme Seeds	Introduce controlling idea in disguised form

Checklist:
	1.	Early scenes = high subtext (SR ≥ 0.7).
	2.	Minimal exposition dumps; facts revealed as conflict ammunition.
	3.	“World language” established (lexicon matching setting/class).

Example (HYPOTHETICAL):

BOSS   You’re new.  
INTERN   You can tell from the enthusiasm.  

→ Subtext: hierarchy, cynicism, tone of world.

⸻

ACT II — Confrontation (#act2)

Function	Dialogue Role
Escalate conflict	Beats shorten; reversals multiply
Reveal moral contradiction	Subtext pressure increases
Midpoint	partial truth leaks
Stakes	verbal tactics harden (from persuade → threaten)

Tempo: mid-act peak; rapid alternation of verbal actions.
Metric Targets: BKI 65 %, SR 0.6–0.7, FES 2.2.

Guideline: At midpoint, dialogue should contradict earlier speech (same topic, new value stance).

⸻

ACT III — Resolution (#act3)

Function	Dialogue Role
Truth emergence	Subtext collapses (SR ↓ to 0.2–0.4)
Thematic statement	spoken or enacted line reveals controlling idea
Relationship culmination	verbal confession, reconciliation, or break
Catharsis	silence or final word acts as release

Checklist:
	1.	One line must flip the story value explicitly (“I was wrong”).
	2.	Dialogue rhythm slows; punctuation elongates; pauses expand.
	3.	Avoid repetition of thematic line—deliver once, then end silence.

G.2 Dialogue at Key Structural Beats  #beats #plot-points

[INTEGRATION FRAMEWORK: merges McKee’s Story beat map with Dialogue micro-mechanics.]

Structural Beat	Dialogue Function	Actionable Technique
Inciting Incident	Spark conflict verbally	Introduce contradiction or unanswerable question
First Act Turn	Reveal hidden motive	Leak subtext; reframe relationship
Midpoint	Reverse previous truth	Echo earlier line with opposite meaning
Second Act Turn	False resolution / betrayal	Add silence or abrupt tonal shift
Climax	Truth spoken / masks drop	Collapse subtext, simplify syntax
Resolution	Emotional clarity / irony	One final verbal action expressing new value

Example:
	•	Inciting Incident: “What if you’re wrong about him?” → seeds story question.
	•	Climax: “I was.” → resolves it.

Guideline: Reuse diction from Act I at Act II Turn with altered tone—verbal echo reveals character growth or decay.

G.7 Dialogue and Thematic Expression  #theme #controlling-idea

Goal: ensure spoken language carries story’s controlling idea without preaching.

G.7.1 Thematic Weaving
	1.	Extract core value pair (freedom/slavery, truth/lie).
	2.	Assign each principal a linguistic motif expressing one side.
	3.	Throughout acts, interlace motifs via argument.
	4.	At climax, motif reversal (same phrase, opposite meaning).

Example:
Opening: “Truth is overrated.” → Climax: “Truth is everything.”

G.7.2 Measurable Consistency
	•	3–5 thematic words recur across acts.
	•	No act adds new theme lexicon after midpoint.
	•	Count repetitions per 20 pages to track control.

G.8 Practical Integration Workflow  #workflow
	1.	Label Structure: mark act/beat points in script.
	2.	Attach Dialogue Goals: per beat, define what dialogue must accomplish.
	3.	Align Metrics: ensure SR curve matches act tension.
	4.	Audit for Reversals: one verbal turning point per structural turn.
	5.	Run Story-Dialogue Sync Test:
	•	If story value turns but dialogue doesn’t → rewrite scene.
	•	If dialogue turns without story consequence → cut or reposition.

H.1.3 Application of Frameworks
