## OVERVIEW: THE DIAGNOSTIC IMPERATIVE

Creative problem-solving in screenwriting and comedy writing requires systematic approaches that convert abstract difficulties into addressable challenges. This part synthesizes diagnostic methodologies from 24 major texts into actionable protocols that writers can apply when encountering obstacles.

### Core Philosophy

**Seger's Diagnostic Mandate**: "Know what's wrong before you fix it"  
**Chitlik's Systematic Approach**: Problems have identifiable causes and systematic solutions  
**Truby's Organic Principle**: Solutions must serve the story's designing principle  
**Johnstone's Reset Protocol**: Creative blocks signal system failures requiring recalibration

## PROTOCOL 1: PROBLEM TAXONOMY & DIAGNOSTIC SYSTEMS

### 1.1 The Creative Problem Classification Matrix

**SOURCE SYNTHESIS**: Seger (Advanced Screenwriting), Chitlik (Rewrite), Blake (Writing the Comedy Movie)

Problems organize into four root cause categories:

| Category | Observable Symptoms | Root Cause | Primary Diagnostic Tool |
|:---------|:-------------------|:-----------|:----------------------|
| **STRUCTURAL** | Pacing issues, unclear acts, momentum loss | Faulty causal logic or tempo | Beat mapping + timing analysis |
| **CHARACTER** | Inconsistent behavior, unclear motivation | Contradictory needs or weak through-line | Character vector analysis |
| **THEMATIC** | Unclear message, muddy values | Unstated moral premise | Value-shift tracking |
| **EXECUTION** | Flat scenes, weak dialogue | Technical craft deficiency | Scene-by-scene audit |

### 1.2 The Three-Phase Diagnostic Process

**PHASE I: DETECTION** (Symptom Identification)
- What isn't working? (Specific, observable)
- Where does it break down? (Page/scene location)
- How severe? (Minor/Moderate/Critical)

**PHASE II: CLASSIFICATION** (Root Cause Analysis)
- Which category? (Structural/Character/Thematic/Execution)
- Primary vs. secondary causes
- Systemic vs. isolated issue

**PHASE III: PRESCRIPTION** (Solution Design)
- Targeted intervention strategy
- Expected outcome metrics
- Validation protocol

### 1.3 Diagnostic Decision Tree

```
START: Problem Identified
│
├─ Is there emotional movement in scenes? → NO → EXECUTION problem (Scene-level repair)
│                                       → YES ↓
│
├─ Is the character behavior consistent? → NO → CHARACTER problem (Motivation repair)
│                                       → YES ↓
│
├─ Is the structure hitting expected beats? → NO → STRUCTURAL problem (Architecture repair)
│                                           → YES ↓
│
└─ Does the story convey clear values? → NO → THEMATIC problem (Meaning repair)
                                      → YES → Problem may be subjective/taste
```

### 1.4 Severity Assessment Protocol

**CRITICAL** (Story-Breaking): Requires immediate attention, affects core premise
**MODERATE** (Flow-Disrupting): Creates reader confusion, slows momentum
**MINOR** (Polish-Level): Refinement issue, affects professional quality

## PROTOCOL 2: STRUCTURAL PROBLEM SOLUTIONS

### 2.1 PROBLEM: Weak or Missing Inciting Incident

**DIAGNOSTIC MARKERS**:
- Story feels slow to start
- Unclear what the story is about
- Reader asks "when does it begin?"

**SOURCE SYNTHESIS**: Field (Screenplay), McKee (Story), Snyder (Save the Cat!)

**SOLUTION PROTOCOL**:

1. **Identify the Central Question**: What one question drives your entire story?
2. **Locate the Disruption**: What event forces the protagonist to act?
3. **Test Clarity**: Can you state the inciting incident in one sentence?
4. **Timing Check**: Does it occur within first 10-15% of runtime?
5. **Causal Verification**: Does everything after flow from this moment?

**REPAIR STRATEGIES**:

| Issue | Solution | Example Application |
|:------|:---------|:-------------------|
| Too subtle | Make external and visible | Show job loss, not just dissatisfaction |
| Too late | Move forward or strengthen setup | Introduce problem by page 10-12 |
| Multiple incidents | Consolidate into single catalyst | Combine related disruptions |
| Unclear stakes | Articulate what protagonist risks | Define what they stand to lose |

**VALIDATION TEST**: Remove the suspected incident. Does the story still make sense? If yes, you haven't found the true inciting incident.

### 2.2 PROBLEM: Saggy Second Act / Middle Muddle

**DIAGNOSTIC MARKERS**:
- Story loses momentum around pages 50-70
- Scenes feel repetitive or circular
- Characters seem to wander aimlessly
- Reader reports boredom

**SOURCE SYNTHESIS**: Seger (Making a Good Script Great), Truby (Anatomy of a Story), Blake (Writing the Comedy Movie)

**SOLUTION PROTOCOL**:

**The Escalation Audit**:
1. Chart conflict intensity per 10-page segment
2. Identify flatlines (no increase in pressure)
3. Map decision points (character choices that change trajectory)
4. Count reversals (expectation vs. outcome gaps)

**STRUCTURAL REPAIR KIT**:

**A. THE MIDPOINT INTERVENTION**
- **Function**: Major shift that recontextualizes everything
- **Types**:
  - **False Victory**: Protagonist thinks they've won (comedies)
  - **False Defeat**: Everything seems lost (dramas)
  - **Revelation**: New information changes understanding
  - **Point of No Return**: Can't go back to old life
- **Placement**: Page 55-60 (110-page script)

**B. THE SUBPLOT INJECTION**
- Add or strengthen B-story that mirrors A-story thematically
- Ensure each subplot scene advances both emotional and plot dimensions
- Create at least 3 intersection points where plots influence each other

**C. THE COMPLICATIONS CASCADE**
- Every 10 pages, introduce new obstacle that makes goal harder
- Use "Yes, but..." or "No, and furthermore..." structure
- Each complication should test different aspect of protagonist

**VORHAUS COMEDY-SPECIFIC FIX**: 
- Verify joke density ≥1 per 2 pages
- Check for "comic escalation" - each setpiece bigger than last
- Ensure character's flaw creates new problems, not just repeats

**VALIDATION METRICS**:
- Conflict intensity rises by ≥15% per act
- No more than 2 consecutive scenes without value shift
- At least 3 major reversals in Act II
- Minimum one decision per sequence that changes trajectory

### 2.3 PROBLEM: Weak Climax

**DIAGNOSTIC MARKERS**:
- Ending feels anticlimactic
- Resolution seems arbitrary or convenient
- Emotional payoff doesn't match buildup
- Deus ex machina solutions

**SOURCE SYNTHESIS**: McKee (Story), Truby (Anatomy of a Story), Snyder (Save the Cat!)

**SOLUTION PROTOCOL**:

**THE CLIMAX INTEGRITY CHECK**:

1. **Maximum Pressure Test**: Is this the worst moment for your protagonist?
2. **Active Choice Test**: Does protagonist actively solve problem (not passive/lucky)?
3. **Integration Test**: Does climax require both external action AND internal growth?
4. **Inevitability Test**: Does everything built up require THIS specific resolution?
5. **Moral Test**: Does the climax embody the story's thematic argument?

**REPAIR STRATEGIES**:

| Weakness | Root Cause | Solution |
|:---------|:-----------|:---------|
| **Too easy** | Stakes not high enough | Raise cost of failure; remove easy outs |
| **Unearned** | Protagonist didn't change | Add character revelation before victory |
| **Confused** | Multiple climaxes competing | Consolidate into single decisive moment |
| **Arbitrary** | Not set up properly | Plant weapons/solutions earlier; Rule of 3s |
| **Passive** | Protagonist is saved, not saving | Rewrite for active protagonist agency |

**TRUBY'S SELF-REVELATION REQUIREMENT**:
- Climax must include moment where protagonist sees truth about themselves
- This insight must be what enables victory (not just coincides with it)
- The revelation should connect to opening weakness/ghost

**COMEDY-SPECIFIC CLIMAX REPAIR**:
- Blake: Ensure comic crisis = maximum absurdity + minimum control
- Vorhaus: Final joke should call back to opening + character flaw
- Must have emotional truth alongside laughs (not just chaos)

### 2.4 PROBLEM: Pacing Issues (Too Fast / Too Slow)

**DIAGNOSTIC MARKERS**:
- Reader feedback: "rushed" or "dragged"
- Uneven scene lengths
- Important moments pass too quickly
- Mundane moments take too long

**SOURCE SYNTHESIS**: Seger (Advanced Screenwriting), Field (Screenplay), Chitlik (Rewrite)

**SEGER'S TEMPO DIAGNOSTIC**:

Calculate **Tempo Function** for each sequence:

```
T = (Beats × Conflict Magnitude) / Scene Duration
```

**Target Range**: 3-7 units per page cluster  
**Flatline** (T consistent across 20+ pages) = boredom risk  
**Spike** (T > 10) = chaos risk

**PACING REPAIR TOOLKIT**:

**TO SLOW DOWN** (when too fast):
- Add **reaction beats**: Show characters processing events
- Expand **decision moments**: Let us see them wrestle with choices
- Insert **breathing room**: Quiet scene between intensity
- **Visceral detail**: Slow-motion-style description of key actions
- **Dialogue expansion**: Let conversations develop naturally

**TO SPEED UP** (when too slow):
- **Cut exposition**: Start scenes late, leave early
- **Combine scenes**: Merge 2-3 scenes into one location
- **Action interruption**: Start conflict mid-scene (in medias res)
- **Compress time**: Montage or jump-cuts in description
- **Raise stakes**: Add deadline pressure

**FIELD'S TIMING PRINCIPLES**:
- Setup: 25-30 pages (establish world + problem)
- Confrontation: 50-60 pages (escalate through complications)
- Resolution: 20-30 pages (climax + aftermath)

## PROTOCOL 3: CHARACTER PROBLEM SOLUTIONS

### 3.1 PROBLEM: Unclear or Weak Motivation

**DIAGNOSTIC MARKERS**:
- Character actions feel random or arbitrary
- Reader asks "why would they do that?"
- Character seems to serve plot rather than drive it
- Inconsistent decision-making

**SOURCE SYNTHESIS**: Truby (Anatomy of a Story), Seger (Making a Good Script Great), McKee (Story)

**TRUBY'S NEED/DESIRE DIAGNOSTIC**:

**THE TWO-TRACK TEST**:
1. **Surface Desire** (External Goal): What do they think they want?
2. **Deep Need** (Internal Transformation): What do they actually need?

These should be:
- **Clear** (statable in one sentence each)
- **Contradictory** (wanting one blocks the other)
- **Driving** (generates all major decisions)

**SOLUTION PROTOCOL**:

**STEP 1: Clarify the Need**
```
Character needs to learn: [psychological/moral lesson]
Because their weakness is: [specific flaw]
Which manifests as: [behavior pattern]
```

**STEP 2: Externalize the Desire**
```
Character wants: [concrete, visible goal]
Which they believe will: [solve their problem]
But actually: [reinforces their weakness]
```

**STEP 3: Create the Moral Choice**
- Design climax that forces choice between want and need
- Getting want = staying broken
- Satisfying need = losing want but becoming whole

**SEGER'S DECISION ARCHITECTURE**:

Map every major character choice against this hierarchy:

| Level | Decision Type | Moral Weight | Example Question |
|:------|:--------------|:-------------|:-----------------|
| **Macro** | Life-direction | High | What kind of person will I be? |
| **Meso** | Relationship/goal | Medium | Do I pursue this or that? |
| **Micro** | Scene-level action | Low | How do I respond right now? |

**Verify**: Every macro decision should flow from established need/weakness.

### 3.2 PROBLEM: Passive Protagonist

**DIAGNOSTIC MARKERS**:
- Things happen TO character, not BY character
- Character reacts more than acts
- Other characters drive plot forward
- Protagonist feels like passenger in own story

**SOURCE SYNTHESIS**: McKee (Story), Field (Screenplay), Truby (Anatomy of a Story)

**THE AGENCY AUDIT**:

Go through script and mark every major story turning point:
- **ACTIVE**: Protagonist makes decision that causes this turn
- **REACTIVE**: Protagonist responds to external force
- **ABSENT**: Turn happens without protagonist involvement

**Healthy Ratio**: 60% Active / 35% Reactive / 5% Absent (maximum)

**SOLUTION STRATEGIES**:

**A. THE DECISION-DRIVEN REWRITE**

Take each reactive moment and ask:
1. What if protagonist's CHOICE created this situation?
2. What preparation could show protagonist planning this?
3. How can I show protagonist adapting actively, not just surviving?

**Example Conversion**:
- **PASSIVE**: "The car breaks down" → Character stranded
- **ACTIVE**: "Character ignores warning light" → Choice creates consequence

**B. THE PURSUIT INVERSION**

Instead of:
- Protagonist FLEEING from antagonist (reactive)

Try:
- Protagonist PURSUING a goal, antagonist BLOCKING (active)

**C. THE ESCALATION PROTOCOL**

After each setback, show:
1. Protagonist recognizes what went wrong
2. Protagonist forms NEW plan (not just tries again)
3. Protagonist takes BIGGER risk in next attempt

**McKEE'S PRINCIPLE**: Character is what character does when the pressure's on.

### 3.3 PROBLEM: Character Inconsistency / Drift

**DIAGNOSTIC MARKERS**:
- Character behaves differently in similar situations without explanation
- Personality shifts to serve plot convenience
- Voice/vocabulary changes between scenes
- Moral stance fluctuates arbitrarily

**SOURCE SYNTHESIS**: Seger (Making a Good Script Great), Truby (Anatomy of a Story)

**SEGER'S CONSISTENCY VECTOR ANALYSIS**:

```
Consistency Score = (Aligned Choices + Coherent Need) / Contradiction Weight

Target: ≥ 0.75
```

**SOLUTION PROTOCOL**:

**THE CHARACTER CONSTITUTION**

Create this document before rewrite:

```
CHARACTER NAME:

CORE WOUND (Ghost): [formative trauma]
DOMINANT BELIEF: [worldview flowing from wound]
BEHAVIORAL PATTERN: [how belief shows in action]
MORAL LINE: [what they will/won't do]
VOICE MARKERS: [3-5 distinctive speech patterns]
CONTRADICTION PERMISSION: [under what circumstances belief breaks]
```

**THE THREE-PASS CONSISTENCY CHECK**:

**PASS 1: Dialogue Voice**
- Read only this character's lines
- Mark any that could be said by someone else
- Add distinctive vocabulary, rhythm, syntax

**PASS 2: Behavioral Logic**
- List every major choice character makes
- Trace each back to core belief
- If disconnect exists, either change choice or show belief evolution

**PASS 3: Growth Continuity**
- Chart character's awareness across script (0-10 scale)
- Should show gradual increase (not sudden jumps)
- Each revelation should build on previous understanding

**TRUBY'S ARC INTEGRITY PRINCIPLE**:

Change must be:
- **Gradual**: Small shifts accumulating
- **Earned**: Through experience, not just time passing
- **Specific**: Not vague "growth" but concrete belief change

## PROTOCOL 4: DIALOGUE PROBLEM SOLUTIONS

### 4.1 PROBLEM: On-the-Nose / Expositional Dialogue

**DIAGNOSTIC MARKERS**:
- Characters say exactly what they mean/feel
- Excessive explanation of plot or backstory
- Dialogue sounds like stage directions read aloud
- Every question gets direct answer

**SOURCE SYNTHESIS**: McKee (Story), Seger (Making a Good Script Great), Vorhaus (The Comic Toolbox)

**McKEE'S SUBTEXT PRINCIPLE**: 

"People rarely say what they mean or mean what they say. They speak in the language of self-protection, manipulation, and social performance."

**THE SUBTEXT TRANSFORMATION PROTOCOL**:

**STEP 1: Identify the Real Need**

For any exchange, determine:
- What does Character A really want from this conversation?
- What does Character B really want?
- What prevents them from stating it directly?

**STEP 2: Create the Oblique Approach**

| Direct (Bad) | Oblique (Better) | Why It Works |
|:-------------|:-----------------|:-------------|
| "I'm angry at you" | "The coffee's cold" | Displacement |
| "I love you" | "I saved you a seat" | Action over statement |
| "This is dangerous" | "My insurance doesn't cover this" | Humor masks fear |
| "I'm the villain" | "I'm a businessman" | Self-justification |

**STEP 3: Add Contradiction Layers**

Words say one thing, but:
- **Tone** says another (sarcasm, false cheer)
- **Body language** contradicts (nervous gestures)
- **Context** undermines (saying "I'm fine" while bleeding)

**SEGER'S EXPOSITION REPAIR KIT**:

**Never directly state information. Instead**:

1. **Dramatize it**: Show through conflict/action
2. **Fragment it**: Spread across multiple scenes
3. **Resist it**: One character doesn't want to hear it
4. **Interrupt it**: Cut off before full explanation
5. **Contradict it**: Different characters give conflicting versions

**THE SUBTEXT DENSITY TEST**:

Calculate ratio:
```
Subtext Score = Implied Meaning / Literal Text

Target: ≥ 0.6 (more subtext than surface)
```

### 4.2 PROBLEM: Weak or Indistinct Character Voices

**DIAGNOSTIC MARKERS**:
- All characters sound alike
- Cover character names, can't tell who's speaking
- Same vocabulary, sentence structure, rhythm
- Interchangeable dialogue

**SOURCE SYNTHESIS**: Seger (Advanced Screenwriting), Vorhaus (The Comic Toolbox)

**THE VOICE DIFFERENTIATION PROTOCOL**:

**DIMENSION 1: Vocabulary**

| Character Type | Word Choice Pattern | Example |
|:--------------|:--------------------|:--------|
| Educated/Formal | Latinate, precise terms | "I comprehend your position" |
| Working-class | Anglo-Saxon, concrete | "I get where you're at" |
| Youth culture | Current slang, shortcuts | "I feel you" |
| Technical mind | Jargon, systematic | "I've processed your input" |

**DIMENSION 2: Sentence Structure**

- **Fragments** vs. **Complete sentences**
- **Questions** vs. **Declarations**
- **Short staccato** vs. **Flowing periods**
- **Active voice** vs. **Passive constructions**

**DIMENSION 3: Rhythm/Cadence**

Listen for:
- Pace (rapid-fire vs. measured)
- Interruption tendency (breaks in vs. lets finish)
- Repetition patterns (echoes, refrains)
- Silence comfort (fills space vs. allows gaps)

**DIMENSION 4: Psychological Signature**

Each character should have distinctive:
- **Defense mechanism** (humor, intellectualization, denial, aggression)
- **Need expression** (asks directly, hints, demands, manipulates)
- **Truth relationship** (honest, evasive, self-deceptive, performative)

**PRACTICAL EXERCISE**:

Write each character answering same question:
"Why did you come here tonight?"

Should get completely different answers in different voices.

### 4.3 PROBLEM: Dialogue Too Efficient (Unnatural)

**DIAGNOSTIC MARKERS**:
- Every line advances plot
- No tangents, interruptions, or false starts
- Characters always understand each other perfectly
- Conversation feels robotic or scripted

**SOURCE SYNTHESIS**: Johnstone (Impro), Sacks (And Here's the Kicker)

**THE NATURAL CHAOS INJECTION**:

Real conversation includes:

**A. MISUNDERSTANDINGS**
- Characters talk past each other
- Mishear or misinterpret
- Project own concerns onto others' words

**B. INTERRUPTIONS & OVERLAPS**
- Finish each other's sentences
- Cut off before point made
- Talk simultaneously

**C. FALSE STARTS & REVISIONS**
- Begin sentence, stop, restart differently
- Search for right word
- Change mind mid-thought

**D. IRRELEVANT TANGENTS**
- Brief distraction by environment
- Sudden memory triggered
- Emotional diversion

**JOHNSTONE'S OFFER-ACCEPTANCE PRINCIPLE**:

Apply "Yes, And" with modifications:
- **Yes, But...** (agreement with complication)
- **No, And Furthermore...** (disagreement with escalation)
- **Yes... [long pause]** (reluctant agreement)

**THE NATURAL RHYTHM FORMULA**:

```
3 Plot-Advancing Lines : 1 Character-Revealing Tangent
```

Tangent establishes voice/relationship; plot lines drive story.

## PROTOCOL 5: COMEDY-SPECIFIC PROBLEM SOLUTIONS

### 5.1 PROBLEM: Jokes Not Landing

**DIAGNOSTIC MARKERS**:
- Reader doesn't laugh where intended
- Setups clear but payoffs weak
- Timing feels off
- Jokes feel forced or telegraphed

**SOURCE SYNTHESIS**: Vorhaus (The Comic Toolbox), Blake (Writing the Comedy Movie), Rosenfield (Mastering Stand-Up)

**VORHAUS'S T+P+D DIAGNOSTIC**:

Every joke needs three elements calibrated:

| Element | Function | Too Low | Too High |
|:--------|:---------|:--------|:---------|
| **Truth (T)** | Recognizability | Absurd, unrelatable | Boring, obvious |
| **Pain (P)** | Stakes/discomfort | Toothless | Cruel, offensive |
| **Distance (D)** | Emotional safety | Too raw, wincing | Too detached, dry |

**Optimal Range**: T: 6-8 / P: 4-6 / D: 5-7 (scale 0-10)

**REPAIR PROTOCOL BY SYMPTOM**:

**Symptom: Joke is mean/uncomfortable**
- Solution: Increase Distance
- Methods: Make absurd, heighten exaggeration, victim is powerful not vulnerable

**Symptom: Joke is boring**
- Solution: Increase Truth or Pain
- Methods: Find more specific detail, raise stakes, add unexpected element

**Symptom: Joke doesn't make sense**
- Solution: Increase Truth
- Methods: Add concrete detail, establish context, use familiar reference points

**THE RULE OF THREE REPAIR**:

Check joke structure:
1. **Setup** (establish pattern)
2. **Reinforcement** (confirm pattern)
3. **Twist** (break pattern unexpectedly)

**Common Failures**:
- **Missing Beat 2**: Audience doesn't recognize pattern (add reinforcement)
- **Telegraphed Beat 3**: Twist is obvious (misdirect in beat 2)
- **Weak Contrast**: Twist too similar to setup (bigger divergence needed)

### 5.2 PROBLEM: Joke Density Issues (Too Many / Too Few)

**DIAGNOSTIC MARKERS**:
- Comedy feels relentless / exhausting (too many)
- Pacing drags, not funny enough (too few)
- Inconsistent tone between scenes

**SOURCE SYNTHESIS**: Blake (Writing the Comedy Movie), Vorhaus (The Comic Toolbox)

**BLAKE'S BEAT DENSITY INDEX (BDI)**:

```
Target: ≥1 comic beat per 30 seconds screen time
Equivalent: ≥1 joke per 2-3 pages of script
```

**DENSITY AUDIT**:

Go through script and mark:
- **Major Jokes** (setup + payoff, standalone laughs)
- **Minor Beats** (small chuckles, wit, physical comedy)
- **Callbacks** (references to earlier material)

Calculate per 10-page segment.

**WHEN TOO DENSE** (>8 beats per 10 pages):

**Solutions**:
1. **Insert Breathing Beats**: Moments of genuine emotion or connection
2. **Remove Weak Jokes**: Cut anything that gets polite chuckle, not real laugh
3. **Slow Setup Expansion**: Give jokes more room to build
4. **Tonal Variation**: Alternate between comedy types (verbal, physical, situational)

**Blake's Rule**: Every 15-20 minutes, need emotional truth moment without jokes.

**WHEN TOO SPARSE** (<3 beats per 10 pages):

**Solutions**:
1. **Mine the Premise**: What's inherently funny about this situation?
2. **Character Comedy**: Use flaw/obsession to generate humor
3. **Add Visual Gags**: Physical comedy requires no dialogue
4. **Dialogue Wit**: Add wordplay, unexpected responses
5. **Callback Opportunities**: Set up earlier, pay off here

**THE ESCALATION REQUIREMENT**:

Each comic setpiece should be bigger than the last:
- Stakes increase
- Absurdity heightens
- More elements in chaos
- Physical scale expands

### 5.3 PROBLEM: Comedy-Drama Tonal Imbalance

**DIAGNOSTIC MARKERS**:
- Jokes undermine emotional moments
- Serious scenes feel out of place
- Tonal whiplash (laugh then shocked/uncomfortable)
- Can't tell what kind of movie this is

**SOURCE SYNTHESIS**: Blake (Writing the Comedy Movie), Vorhaus (The Comic Toolbox), Seger (Making a Good Script Great)

**THE TONAL INTEGRATION PROTOCOL**:

**PRINCIPLE**: Comedy and drama should serve the same thematic core, not fight each other.

**BLAKE'S TONAL SIGNATURE**:

Define your specific blend:

| Type | Comedy % | Drama % | Example Films | Key Principle |
|:-----|:---------|:--------|:--------------|:--------------|
| **Broad Comedy** | 80% | 20% | Dumb and Dumber | Jokes primary, emotion validates |
| **Comedy-Drama** | 60% | 40% | Silver Linings Playbook | Equal partnership |
| **Dramedy** | 40% | 60% | Little Miss Sunshine | Drama primary, comedy releases |
| **Dark Comedy** | 50% | 50% | Fargo | Comedy from horror creates distance |

**Maintain consistency within ±10% throughout script.**

**THE HEART-BEAT INTEGRATION**:

**Vorhaus's Heart Principle**: Every major comic sequence needs emotional truth.

**Structure**:
1. **Comic Setup** (2-3 pages of escalating chaos)
2. **Heart Beat** (30-60 seconds of genuine emotion)
3. **Comic Resolution** (callback that acknowledges emotional truth)

**Example Pattern**:
- Setup: Character's flaw creates disaster (comedy)
- Heart: They recognize they've hurt someone (drama)
- Resolution: They make amends in flawed way (comedy + growth)

**TONAL SAFETY PROTOCOLS**:

**Don't**:
- Joke immediately after serious character revelation
- Make comedy at expense of story's moral center
- Use humor to avoid earned emotional moments

**Do**:
- Let silence follow major emotional beats
- Use comedy to illuminate character truth
- Allow characters to be genuinely hurt/vulnerable

## PROTOCOL 6: CREATIVE BLOCK SOLUTIONS

### 6.1 PROBLEM: Writer's Block / Creative Paralysis

**DIAGNOSTIC MARKERS**:
- Staring at blank page
- Everything written seems terrible
- Can't make decisions
- Overwhelming self-doubt

**SOURCE SYNTHESIS**: Seger (Advanced Screenwriting), Johnstone (Impro), Sacks (Poking a Dead Frog)

**SEGER'S FOUR-PHASE CREATIVE CYCLE**:

Identify which phase is blocked:

| Phase | Function | When Blocked | Solution |
|:------|:---------|:-------------|:---------|
| **Preparation** | Gather material | Don't know what to write | Research, outline, interviews |
| **Incubation** | Unconscious processing | Forcing too hard | Step away, do other activity |
| **Illumination** | Insight arrives | Can't find answers | Free-write, no judgment |
| **Verification** | Test & refine | Paralyzed by criticism | Separate creation from editing |

**THE INCUBATION PROTOCOL**:

When stuck, systematically step away:
1. **Physical activity** (walk, exercise - 30-60 min)
2. **Creative displacement** (read, watch unrelated content)
3. **Sleep** (problems often solve overnight)
4. **Return fresh** (after minimum 2-hour break)

**The brain continues working when you're not consciously thinking about it.**

**JOHNSTONE'S "PERMISSION TO FAIL" RESET**:

Creative blocks often come from fear of being wrong.

**Solution: Intentionally Write Badly**

- Set timer for 10 minutes
- Write the WORST possible version deliberately
- Don't stop, don't judge, just keep going
- Often by minute 7-8, something good emerges

**The inner critic relaxes when you've already "failed" by choice.**

### 6.2 PROBLEM: Decision Paralysis (Multiple Options, Can't Choose)

**DIAGNOSTIC MARKERS**:
- Several equally valid story directions
- Can't decide between character choices
- Endless outlining without writing
- Fear of committing to "wrong" choice

**SOURCE SYNTHESIS**: Seger (Advanced Screenwriting), Truby (Anatomy of a Story)

**THE DECISION HIERARCHY TEST**:

When stuck between options, evaluate against hierarchy:

**Level 1: Premise Alignment**
- Which option better serves your core story question?

**Level 2: Thematic Resonance**  
- Which embodies your theme more clearly?

**Level 3: Character Truth**
- Which feels most authentic to who this character is?

**Level 4: Audience Impact**
- Which creates stronger emotional experience?

**Level 5: Practical Execution**
- Which is more filmable/stageable?

**First option that wins 3/5 criteria is your choice.**

**THE "JUST PICK ONE" PROTOCOL**:

When truly stuck:
1. **Coin flip** (genuinely random choice)
2. **Write full draft** with that option
3. **If it feels wrong**, you'll know within 10 pages
4. **If it feels right**, your subconscious already knew

**Truby's Principle**: "The story knows what it needs. Your job is to listen, not control."

### 6.3 PROBLEM: Overwhelm / Too Much to Fix

**DIAGNOSTIC MARKERS**:
- Notes or feedback feel insurmountable
- Don't know where to start
- Every scene seems broken
- Considering abandoning project

**SOURCE SYNTHESIS**: Chitlik (Rewrite), Seger (Making a Good Script Great)

**CHITLIK'S SEVEN-PASS SYSTEM** (Sequential Focus):

**Never try to fix everything at once. Instead**:

| Pass | Focus ONLY On | Ignore Everything Else |
|:-----|:--------------|:-----------------------|
| **1. Structure** | Act breaks, turning points, causality | Dialogue, description, details |
| **2. Character** | Motivation, arc, consistency | Pacing, jokes, polish |
| **3. Theme** | Moral argument, values, message | Individual lines, formatting |
| **4. Scene** | Each scene's purpose and turn | Dialogue quality, grammar |
| **5. Dialogue** | Subtext, voice, efficiency | Typos, description |
| **6. Polish** | Grammar, format, clarity | Big picture changes |
| **7. Delivery** | Professional presentation | Creative content |

**Complete one full pass before starting next.**

**THE TRIAGE PROTOCOL**:

When overwhelmed, categorize problems:

**CRITICAL** (Must fix or story doesn't work):
- Focus 80% of energy here
- Fix these first, in order of severity

**IMPORTANT** (Should fix for professional quality):
- Address after critical issues resolved
- May require single focused pass

**MINOR** (Nice to have, polish-level):
- Save for final pass
- Some may never get addressed (that's okay)

**Seger's Wisdom**: "Perfect is the enemy of done. Good enough to move forward beats paralyzed by impossible standards."

## PROTOCOL 7: EMERGENCY REPAIR PROTOCOLS

### 7.1 QUICK FIX: Scene Feels Flat (No Energy)

**5-MINUTE DIAGNOSTIC**:

1. ✓ **Does the scene have a value shift?** (positive → negative or vice versa)
   - NO → Add reversal or remove scene
   
2. ✓ **Is there conflict?** (opposition between characters or internal struggle)
   - NO → Add obstacle or contrary goal
   
3. ✓ **Does something change?** (information, relationship, situation)
   - NO → Something must be different by scene end

**RAPID SOLUTIONS**:

| Problem | 2-Minute Fix |
|:--------|:-------------|
| No conflict | Give second character opposite goal |
| No stakes | Add deadline or cost of failure |
| Too much agreement | Character resists, needs persuading |
| No surprise | Add unexpected information mid-scene |

### 7.2 QUICK FIX: Opening 10 Pages Not Working

**IMMEDIATE ACTIONS**:

1. **Kill the Setup**: Start 3 pages later, drop backstory
2. **External + Internal**: Show character in action WHILE revealing character
3. **Question + Mystery**: Make us wonder something immediately
4. **Visual Impact**: Describe something we haven't seen before
5. **Voice Punch**: First line of dialogue should be distinctive

**THE OPENING PAGE TEST**:

First page must establish:
- **Genre** (what kind of story is this?)
- **Tone** (serious? funny? dark?)
- **World** (where/when are we?)
- **Character** (whose story is this?)
- **Question** (what are we wondering?)

If missing any, add.

### 7.3 QUICK FIX: Dialogue Scene Running Too Long

**COMPRESSION TECHNIQUES**:

1. **Enter Late, Leave Early**: Cut first and last exchanges
2. **Kill Small Talk**: Remove greetings, goodbyes, transitional chat
3. **Interrupt**: Don't let characters finish thoughts
4. **Subtext Only**: Remove any directly stated information
5. **Action During**: People do things while talking (cut static exchanges)

**THE 50% RULE**: Try cutting half the dialogue. If scene still works, it was bloated.

### 7.4 QUICK FIX: Ending Doesn't Satisfy

**FOUR ESSENTIAL QUESTIONS**:

1. **Did protagonist EARN the ending?** (through their choices and growth)
   - If NO: Add decision that demonstrates character change
   
2. **Does ending EMBODY the theme?** (show the moral argument's resolution)
   - If NO: Adjust resolution to demonstrate thematic lesson
   
3. **Are EXTERNAL and INTERNAL stories resolved?** (both plot and character arc)
   - If NO: Ensure both dimensions conclude
   
4. **Is there an EMOTIONAL MOMENT** before final beat?
   - If NO: Add intimate character beat after climax

**COMMON QUICK FIXES**:

| Issue | Solution |
|:------|:---------|
| Too abrupt | Add 1-2 page aftermath showing new normal |
| Feels incomplete | Address one unanswered question |
| Too neat/tidy | Add bittersweet element or cost |
| Unclear meaning | Add visual or dialogue callback to theme |

## PROTOCOL 8: ADVANCED DIAGNOSTIC TOOLS

### 8.1 The Scene Energy Audit

**Process**:
1. List every scene in script
2. Rate each scene's emotional energy: +2 (very positive) to -2 (very negative)
3. Chart on graph

**Healthy Pattern**: Should show wave motion (ups and downs) with general escalation

**Red Flags**:
- Flat line (no variation = boring)
- All positive (no conflict)
- All negative (exhausting)
- No escalation (doesn't build)

### 8.2 The Character Presence Matrix

**Tool to diagnose supporting character overuse/underuse**:

Create grid:
- **Rows**: All characters
- **Columns**: Every 10-page segment

Mark presence with: M (major role), m (minor role), blank (absent)

**Analysis**:
- Protagonist should have M in 80%+ of segments
- Any character absent >40 pages should probably be cut or given subplot
- Too many characters sharing scenes dilutes focus

### 8.3 The Dialogue Efficiency Test

**Process**:
1. Take 10-page dialogue-heavy section
2. Rewrite cutting 30% of dialogue
3. Compare versions

**Question**: Does shortened version:
- Move faster?
- Create more tension?
- Force more subtext?

If YES to all three, original was too verbose.

### 8.4 The Thematic Clarity Test

**Ask three people** (who've read script):
"What do you think this story is about? (Theme, not plot)"

**Scoring**:
- All three give similar answer = **Clear** (9-10/10)
- Two similar, one different = **Mostly Clear** (7-8/10)
- All three different answers = **Unclear** (0-6/10)

If unclear, theme needs more consistent expression throughout.
