1.2 Premise and Concept Verification (#narrative-seed)

Seger’s first directive: clarify what the story is really about.
PK automation formalizes this as:

def validate_premise(premise:str, theme:str)->float:
    clarity = semantic_overlap(premise,theme)
    irony = detect_irony(premise)
    motion = check_action_verb(premise)
    return (clarity*0.6 + irony*0.2 + motion*0.2)

Evaluation ≥ 0.85 = “solid dramatic question.”
Writers repeat until both clarity and emotional promise score high.

Seger’s “Premise Question”—“What is the human truth beneath the plot?”—becomes a quantitative threshold.

⸻

1.3 Structural Audit (#story-architecture)

Seger’s three-movement design (setup / confrontation / resolution) operates as energy transfer.
PK executes a Causality Graph Test:
	1.	Map beats as nodes.
	2.	Assign each node value change (+/–).
	3.	Measure Δ value continuity per act.

If cumulative Δ drops > 15 % between acts, structural momentum is flagged “leak.”
Remedy = insert decision beat or re-motivate turning point.

This quantifies Seger’s intuition that weak acts stem from missing choices, not missing events.

⸻

1.4 Character Calibration (#transformational-vector)

Seger’s want vs need model is encoded as vector alignment:

vector_angle = arccos( dot(want, need) / |want||need| )

Angle	Diagnosis	Instruction
0–15°	Aligned	Sustain arc through escalation
16–45°	Partial mis-alignment	Clarify need through reversal
>45°	Conflict collapse	Rewrite motivation source

Seger’s rule—“Conflict must reveal theme”—is verified when vector alignment to theme axis > 0.9.

1.5 Scene and Dialogue Optimization (#micro-structure)

Seger treats scenes as self-contained stories.

Test	Target	Meaning

Causality Link	1.0	Motivated entry / exit
Conflict Amplitude	> 0	Active pressure
Dialogue Density	≤ 10 % redundancy	Subtext efficient
Beat Rhythm Variance	σ ≥ 0.3	Rhythmic variety

Fail flags trigger Seger’s rewrite questions: _“Whose scene is it?” _ and “What changes?”

1.8 Seger Rewrite Algorithm v4.0 (#pseudo-code)

def seger_rewrite(script):
