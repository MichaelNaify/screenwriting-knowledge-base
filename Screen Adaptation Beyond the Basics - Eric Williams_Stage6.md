7.4 Multi-Objective Optimization (MOO) Framework (#moo)

We treat improvement as a Pareto problem with objectives: maximize CH, EH, OH simultaneously.

Decision variables (bounded by Stage 5 feasibility):
	•	Beat timing (affects Ti, ΔE)
	•	Information reveal order (ΔK, Nc)
	•	Character choice pressure (Mv, VE)
	•	Localization choices (Ci, Ct)
	•	Editorial rhythm (Ti σ, Cq)

Constraints:
	•	EH ≥ 0.75 (no ethically-negative optima)
	•	Drift ≤ 0.02 vs previous checkpoint
	•	Rb budget from §6.11 (rewrite cap)

Search procedure: weighted A/B rewrite experiments per scene, evaluate deltas, accept only Pareto-improving changes (no objective worsens).
#pareto #ab-testing #rewrite-science

7.5 Gradient-of-Change Heuristic (#gradient)

To avoid over-tuning, Stage 6 uses small-step gradients:
	•	Accept changes with ΔCH ≥ +0.02 and ΔEH ≥ 0 and ΔOH ≥ 0.
	•	If ΔCH < +0.02 across two loops, pivot variable (e.g., shift from ΔK edits to Ti).
	•	Never stack more than 3 variable edits per scene in one loop (prevents causal ambiguity).
