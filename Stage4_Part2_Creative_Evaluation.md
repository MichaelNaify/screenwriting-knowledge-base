## §0 | INTRODUCTION TO CREATIVE WORK EVALUATION

### §0.1 | Philosophy of Assessment

Creative work evaluation balances **objective craft standards** with **subjective artistic merit**. This system prioritizes:

**Evidence-Based Criteria:** Every score requires textual/behavioral evidence  
**Developmental Sensitivity:** Beginner vs. professional standards explicitly distinguished  
**Actionable Feedback:** Every weakness linked to Stage 3 improvement protocols  
**Integration Transparency:** Multi-source synthesis quality measured as distinct dimension  
**Contextual Appropriateness:** Genre, format, and market context shape expectations

**Core Principle:** Assessment serves growth. Every evaluation must empower revision, never merely judge.

The rubrics in this document represent the synthesis of assessment frameworks from McKee (Story evaluation principles), Truby (organic story testing), Field (structural assessment), Seger (rewrite diagnostics), and integrated approaches across all Stage 0-3 documented methodologies.

### §0.2 | How to Use These Rubrics

**Step 1: Select Appropriate Rubric**
- Match work type to rubric (feature screenplay, TV pilot, sketch, etc.)
- Choose developmental tier (student/emerging/professional)
- Identify genre-specific framework if applicable

**Step 2: Dimensional Assessment**
- Evaluate each dimension independently before aggregation
- Record specific evidence for each score
- Note both strengths and weaknesses with page/scene references
- Use [VERIFY] tags (Part 1 §4.2) when uncertain about criteria

**Step 3: Calculate Weighted Score**
- Apply dimension weights per rubric
- Calculate overall score
- Convert to letter grade for summary communication
- Check against minimum thresholds for context

**Step 4: Generate Actionable Feedback**
- Identify 3-5 priority improvement areas
- Route each weakness to specific Stage 3 protocols
- Provide clear revision roadmap with expected outcomes
- Include resource recommendations (specific Stage 0-3 sections)

**Step 5: Benchmark (if appropriate)**
- Compare to Part 5 professional standards if assessing market readiness
- Identify gap between current state and target state
- Provide strategic guidance on submission timing

**Important:** Never use rubrics mechanistically. Scores inform judgment but don't replace it. Always provide qualitative context alongside quantitative assessment.

### §0.3 | Scoring Calibration Standards

**Inter-Rater Reliability Target: ≥90%**

Trained evaluators using these rubrics should score the same work within ±5 points (on 100-point scales) or ±3% on overall scores.

**Calibration Protocol:**

1. **Training Phase:** Evaluators study rubrics + practice on 10 sample works with established scores
2. **Verification Phase:** Evaluators independently score 5 test works without discussion
3. **Variance Analysis:** Score differences analyzed; >5% variance requires recalibration discussion
4. **Consensus Building:** Disagreements resolved through evidence discussion, criteria refinement
5. **Ongoing Monitoring:** Quarterly re-calibration ensures consistency maintenance over time

**Evidence Requirements for All Assessments:**

- Every score must cite specific textual evidence (scene numbers, page numbers, dialogue examples)
- Subjective impressions noted separately but not weighted without supporting textual analysis
- Stage 0-3 concepts explicitly referenced to ground assessment in documented frameworks
- Multiple examples provided for pattern claims (e.g., "dialogue lacks subtext" requires 3-5 examples)

**Bias Mitigation (Per Part 1 §10.2):**

- Evaluators trained on common bias patterns (halo effect, confirmation bias, recency bias)
- Assessment includes bias-check questions
- Diverse evaluator panels for high-stakes assessments
- Statistical monitoring of scoring patterns across evaluators

## §1 | FEATURE SCREENPLAY EVALUATION (DRAMA)

### §1.1 | Evaluation Philosophy

Feature drama assessment measures how effectively a script creates **meaningful emotional experience through causally linked events that reveal character and theme**. 

Integration of:
- McKee's story physics (Stage 0 §2): Value change, causality, controlling idea
- Truby's organic structure (Stage 0 §3): Character-driven design, moral argument, 22 building blocks
- Field's paradigm (Stage 0 §1): Three-act structure, plot points, page-based pacing
- Seger's craft principles: Scene analysis, relationship dynamics, subtext

provides the multi-dimensional assessment foundation.

**What Constitutes Quality in Feature Drama:**

- **Structural integrity:** Clear causal progression, escalating complications, satisfying resolution that proves controlling idea
- **Character depth:** Dimensional protagonists with clear wants/needs, authentic psychological grounding, believable arcs
- **Thematic coherence:** Controlling idea demonstrated through action patterns, not stated in dialogue
- **Emotional authenticity:** Genuine feeling earned through specific dramatic choices under pressure
- **Craft excellence:** Professional execution across all technical dimensions (format, pacing, visual writing)

**Assessment Balance:**

- 60% Objective craft measures (structure mechanics, character architecture, dialogue technique)
- 40% Subjective artistic merit (originality, emotional resonance, thematic depth, vision)

This balance ensures that both technical competence and artistic achievement receive appropriate weight. A script can be technically flawless yet emotionally inert (low artistic merit) or brilliantly conceived yet poorly executed (low craft).

**Developmental Context Matters:**

These standards represent **professional/market-ready expectations**. For student/beginner work, apply developmental lenses (see §5.3) that assess growth trajectory and principle comprehension alongside absolute quality.

### §1.2 | MULTI-DIMENSIONAL SCORING MATRIX

**TOTAL POSSIBLE: 600 POINTS**

The rubric assesses six major dimensions, each worth 100 points. Dimensions are evaluated independently then aggregated for overall score. This prevents halo effects (one strong dimension inflating others) and enables precise diagnostic feedback.

---

#### **DIMENSION 1: STRUCTURAL INTEGRITY (100 points)**

Structure is the skeleton that supports all other elements. McKee: "Structure is a selection of events from the characters' life stories that is composed into a strategic sequence to arouse specific emotions and express a specific view of life" (Stage 0 §2.1).

This dimension assesses how well the script's temporal architecture serves its dramatic purpose.

---

**Premise Strength (15 points)**

The premise is the narrative DNA from which all structure grows. A weak premise cannot generate strong structure no matter how skilled the execution.

**Scoring Criteria:**

**13-15 points (Excellent):** Passes Truby's premise test (Stage 0 §3.2) - premise is morally compelling, causally generative, and uniquely framed. Clearly implies both external goal (want) and internal journey (need). McKee's controlling idea (Stage 0 §2.4) evident in premise design - the central value and its trajectory visible in the setup. Premise creates natural conflict without contrivance.

**10-12 points (Good):** Strong premise with minor clarity issues. Either moral dimension slightly fuzzy OR causal implications not fully developed, but core is solid and workable. One or two elements need sharpening.

**7-9 points (Adequate):** Present but unfocused. Premise doesn't clearly generate ongoing conflict or lacks sufficient moral weight to sustain feature length. Generic or too familiar without distinctive angle.

**0-6 points (Weak):** Weak, absent, or fundamentally flawed. Generic to the point of derivative, so vague it provides no structural foundation, or concept that cannot sustain 90-110 minutes.

**Evidence Requirements:**

1. Can premise be stated in single sentence showing protagonist + desire + obstacle + stakes?
2. Does premise imply character transformation (beginning state ≠ ending state)?
3. Is premise demonstrated in opening 10 pages (setup) and climax (proof)?
4. Does premise suggest moral question that drives dramatic choices?

**Operational Test:** 
Cover the script and try to pitch the premise in 30 seconds. If you cannot articulate a clear, compelling premise, neither can the writer, suggesting structural weakness at the foundation.

**Source Grounding:** 
- Truby pp. 29-45 (designing principle/"premise")
- McKee pp. 115-127 (controlling idea)
- Stage 0 §3.2 (Premise as narrative engine)
- Stage 1 Truby Analysis §3 (Premise construction principles)

**Stage 3 Route for Deficiency:**

**Three-Act Structure (15 points)**

Field's paradigm remains the industry standard structural framework. Even scripts that innovate or subvert structure benefit from understanding the expectation they're working with or against.

**Scoring Criteria:**

**13-15 points (Excellent):** Field's paradigm (Stage 0 §1.3) clearly executed. Plot Point 1 occurs at appropriate page range (typically pp. 25-30 in 110-page script, ~22-27% through story). Act II subdivided at midpoint (pp. 50-60) with clear reversal or escalation. Plot Point 2 (pp. 85-90) creates crisis necessitating climax. Act proportions approximately 1:2:1 supporting appropriate pacing. Structure feels inevitable not imposed.

**10-12 points (Good):** Structure present but timing slightly off (Plot Points 2-5 pages early/late) OR midpoint weak/absent but other elements solid. Act proportions may create minor pacing issues (e.g., 25-page Act I feels rushed; 70-page Act II drags) but nothing severe.

**7-9 points (Adequate):** Three acts identifiable but beats missing or significantly misplaced. Structure feels imposed rather than organic - can see the scaffolding. Midpoint may be absent or Act II lacks clear forward momentum. Proportions significantly off (e.g., 35-page Act I, 50-page Act II).

**0-6 points (Weak):** No clear structure OR severe structural problems (e.g., 60-page Act II with no turns, missing climax, unclear act breaks). Story feels shapeless or structurally incoherent.

**Evidence Requirements:**

1. Plot Point 1: Page number and nature of turning point (new situation/information that spins story)
2. Midpoint: Page number and reversal mechanism (false victory/defeat, new information, escalation)
3. Plot Point 2: Page number and crisis nature (how it necessitates climactic confrontation)
4. Act proportion analysis: Should approximate 25:50-60:25-35 in 110-page script
5. Verify each major turn CHANGES SITUATION not just continues it

**Common Structural Failures:**
- Late Plot Point 1 (p. 40+) = dragging first act, late story start
- Missing/weak midpoint = Act II drift, lack of escalation
- Early Plot Point 2 (p. 75) = rushed ending, insufficient complication
- Proportional imbalance = pacing problems (rushed or dragging)

**Source Grounding:**
- Field pp. 89-124 (the paradigm)
- Stage 0 §1.3 (Three-act structure synthesis)
- Stage 1 Field Analysis §5 (Paradigm mechanics)
- McKee pp. 221-245 (acts and sequences) for theoretical grounding

**Stage 3 Route:**

**Causal Logic (15 points)**

The single most important structural principle: every event must be caused by prior event or character choice. McKee: "Nothing happens by chance. Each event is caused by the ones that precede it" (Stage 0 §2.3).

**Scoring Criteria:**

**13-15 points (Excellent):** Every major event caused by prior event or character choice under pressure. McKee's "law of conflict" (Stage 0 §2.3) maintained - events progress through causality not coincidence. Audience can trace clear cause-effect chain from inciting incident through climax. "Therefore/but" construction (Truby) rather than "and then." Character choices create situations; situations force choices; choices reveal character in escalating pattern.

**10-12 points (Good):** Mostly causal with 1-2 weak links. Some coincidence present but doesn't break overall narrative logic. Minor convenience (e.g., character arrives at exactly right moment once) but generally tight causality.

**7-9 points (Adequate):** Episodic feeling. Events happen in sequence but causal connections unclear or weak. "And then this happened, and then that happened" structure rather than "because of this, that happened." Plot feels somewhat arbitrary.

**0-6 points (Weak):** Random events, deus ex machina solutions, severe logic gaps. Major plot turns rely on coincidence or contrivance. No clear causal through-line. Audience constantly wondering "why did that happen?" or "how did they know that?"

**Evidence Requirements:**

1. Map 10 major story events in cause-effect chain (each event should be EFFECT of prior, CAUSE of next)
2. Identify any coincidences or conveniences (protagonist "just happens to" encounter key information)
3. Verify each turning point results from character choice under pressure, not random occurrence
4. Check climax results causally from all preceding story events

**The Coincidence Test:**
One coincidence to GET the protagonist INTO trouble = acceptable (inciting incident)
Coincidence to GET protagonist OUT of trouble = unacceptable (deus ex machina)

**Source Grounding:**

**Progressive Complications (15 points)**

Structure must escalate. Each complication should increase stakes, narrow protagonist options, or deepen character investment. The pressure curve should trend upward.

**Scoring Criteria:**

**13-15 points (Excellent):** Escalating conflict pattern throughout. Each complication increases stakes (more to lose), narrows options (fewer ways out), or deepens investment (personal becomes more personal). Pressure increases geometrically not linearly - Act III complications dwarf Act I. Final complication creates maximum jeopardy immediately before climax, making climax feel necessary and inevitable.

**10-12 points (Good):** Generally escalating but plateau in Act IIB or one sequence that doesn't escalate adequately. Overall trajectory upward but not perfectly smooth. Some complications feel repetitive in intensity rather than progressive.

**7-9 points (Adequate):** Complications present but don't clearly escalate. Flat conflict curve - similar intensity obstacles throughout. Climax doesn't feel like highest-stakes moment because earlier complications equally intense.

**0-6 points (Weak):** No clear escalation pattern. Random conflict without building pressure. May actually de-escalate (big problem early, smaller problems later). Climax arrives without sufficient complication buildup.

**Evidence Requirements:**

1. Chart stakes across 8-10 major complications on scale of 1-10 (should trend upward)
2. Verify each complication narrows protagonist options (fewer resources, less time, more opposition)
3. Confirm Act III complications exceed Act I complications in intensity
4. Check final complication creates true crisis (no obvious solution) requiring climactic choice

**Escalation Types (all valid):**
- **External escalation:** Physical jeopardy increases
- **Internal escalation:** Emotional/psychological stakes deepen  
- **Moral escalation:** Ethical compromises required intensify
- **Temporal escalation:** Deadlines compress
- **Social escalation:** More people affected/involved
- **Combination:** Multiple escalation types compound

**Source Grounding:**

- McKee pp. 234-256 (progressive complications)

**Scene-Level Turning Points (20 points)**

The most important micro-structural principle. McKee: "Nothing moves in a story except through scenes" (Stage 0 §2.6). Every scene must turn value from positive to negative or vice versa.

**Scoring Criteria:**

**17-20 points (Excellent):** McKee's "beat" principle (Stage 0 §2.6) rigorously applied - every scene turns value state. 80%+ of scenes demonstrate clear value change. No dead scenes (scenes that only deliver information without dramatic turn). Each scene advances plot AND character AND theme simultaneously - triple duty. Scenes feel like discrete dramatic units, not mere coverage of events.

**14-16 points (Good):** Most scenes turn but 20-30% are flat (deliver information or show character travel but don't change dramatic value). OR all scenes turn but integration with character/theme sometimes weak (pure plot advancement).

**10-13 points (Adequate):** Many scenes lack clear turning points. Scenes feel like "coverage" of events rather than dramatic units. Informational or transitional scenes frequent. Single dimension advancement (plot moves but character/theme static).

**0-9 points (Weak):** Scenes don't turn values consistently. Expository, static, or merely transitional throughout. No clear understanding of scene as dramatic unit with beginning value state, turning point, and changed value state.

**Evidence Requirements:**

1. Analyze 10 sample scenes across acts - identify value at start and end
2. Verify value change present and motivated by character choice or new information
3. Confirm scene turns are genuine (not just movement from location A to B)
4. Check scenes advance multiple dimensions (plot, character, theme) not just single dimension

**The Scene Value Test:**
- Beginning value state: Fear of exposure (negative)
- Turning point action: Character reveals secret despite risk
- Ending value state: Liberation through truth (positive)
= CLEAR TURN

Vs. weak scene:
- Beginning: Character at home
- Action: Character travels to work, thinks about problem
- Ending: Character arrives at work
= NO TURN (just transition)

**Common Scene Failures:**
- Exposition dumps (information without dramatic turn)
- Repeated beats (same argument/obstacle multiple times without escalation)
- Transition scenes (travel, preparation that don't turn values)
- Placeholder scenes (obviously present because plot requires event, not because scene has dramatic life)

**Climactic Resolution (20 points)**

The climax must demonstrate the controlling idea through protagonist's final choice under maximum pressure. Resolution must answer all major questions (plot, character, theme) while avoiding convenient wrap-up.

**Scoring Criteria:**

**17-20 points (Excellent):** Climax clearly demonstrates controlling idea (McKee) through protagonist's final choice under maximum pressure. All major dramatic questions answered (plot resolution, character arc completion, thematic statement). Snyder's "Final Image" (Stage 0 §4.5) echoes opening but shows transformation. Emotionally satisfying without sentimentality. Inevitable yet surprising. Resolution period appropriate to genre/tone (not over-explained or too abrupt).

**14-16 points (Good):** Solid climax and resolution but minor questions unanswered (typically secondary subplot) OR thematic statement slightly muddled. Emotional impact strong but could be stronger. Perhaps resolution beat or two missing or final image doesn't fully echo opening transformation.

**10-13 points (Adequate):** Climax present but rushed, convenient, or resolution too neat. May rely on coincidence or character suddenly knows what to do without sufficient setup. Some major questions unresolved. Thematic payoff weak - not clear what story proved. Or opposite: over-explained resolution that doesn't trust audience.

**0-9 points (Weak):** No clear climax (fizzles out), unresolved major plot threads (audience left confused about outcomes), resolution contradicts setup (violates promises made), or climax doesn't involve protagonist making real choice. Deus ex machina endings.

**Evidence Requirements:**

1. Identify climactic choice and what it demonstrates about controlling idea (link to premise/theme)
2. Verify all major plot threads resolved OR deliberately left open per genre conventions
3. Confirm character arc completes in climax (transformation demonstrated through climactic choice)
4. Check final image contrasts with opening image showing transformation
5. Assess emotional satisfaction - does ending FEEL complete?

**Climax Quality Tests:**
- **Controlling Idea Test:** Can you articulate how climax proves premise/theme?
- **Character Arc Test:** Does climax require character growth to succeed?
- **Maximum Pressure Test:** Is this truly the highest-stakes moment?
- **Inevitability Test:** Looking back, was this the only possible ending?
- **Surprise Test:** Despite inevitability, did anything surprise in execution?

**Common Climax Failures:**
- Convenient solutions (sudden rescue, coincidental information)
- Climax doesn't require character arc (hero could have won in Act I)
- Wrong character solves problem (mentor/ally does what protagonist should)
- Anti-climactic (bigger crisis occurred earlier in Act II)
- Over-explained (tells audience what everything meant)
- Too abrupt (no resolution period, credits roll immediately after climax)

#### **DIMENSION 2: CHARACTER DEVELOPMENT (100 points)**

Character is the conduit through which story energy flows. McKee: "True character is revealed in the choices a human being makes under pressure" (Stage 0 §5.1). This dimension assesses the depth, authenticity, and transformation of characters.

---

**Dimensional Complexity (20 points)**

The single most important character quality. One-dimensional characters = types. Two-dimensional characters = having contradictions. Three-dimensional characters = contradictions that surprise yet feel inevitable given psychology.

**Scoring Criteria:**

**17-20 points (Excellent):** McKee's dimension test passed (Stage 0 §5.2) - protagonist demonstrates contradictory traits revealed through contrasting choices in different contexts. Character surprises audience yet remains psychologically consistent. Supporting cast also dimensional (not mere types or functions). Behavior authentic to established psychology. Contradictions create depth without incoherence.

Example: Character is both brave (defends friend) AND cowardly (won't face personal fear), revealed through behavior in different situations that test different aspects of psychology.

**14-16 points (Good):** Protagonist dimensional with clear contradictions, but supporting cast somewhat flat OR all characters consistent but lack surprising depth. Contradictions present but predictable rather than revealing.

**10-13 points (Adequate):** Characters show some complexity but lean toward types. Behavior sometimes serves plot over psychology. Hero dimensional but others are functions (mentor, ally, comic relief) without own psychology. Contradictions stated rather than demonstrated.

**0-9 points (Weak):** Flat characters, types, stereotypes. All heroes all good, all villains all bad. Behavior inconsistent (character does what script needs) or purely functional (exists only to create plot event or deliver information).

**Evidence Requirements:**

1. Identify 3+ contradictory traits in protagonist with specific scene evidence for each
2. Document moments character surprises audience while remaining believable
3. Assess supporting cast dimensionality - analyze 2-3 key characters beyond protagonist
4. Verify contradictions create psychological depth not just random behavior
5. Check behavior remains consistent with established psychology even when surprising

**Dimension Test (McKee):**
- Positive trait shown in one context: Character generous (gives money to homeless)
- Negative trait shown in another: Character stingy (haggles over small bill at restaurant)
- Resolution: Both are true because generosity extends to strangers, stinginess toward services

This paradox reveals DIMENSION. Same behavior in all contexts = flat.

**Common Failures:**
- **The Saint:** All positive traits, no flaws = unbelievable
- **The Monster:** All negative traits, no redeeming qualities = unrelatable
- **The Inconsistent:** Behavior changes without psychological cause = incoherent
- **The Function:** Character exists only to serve plot = not fully human
