### **PATH 1: FOUNDATION TRACK (Months 1-6)**
**Goal**: Establish solid screenwriting fundamentals
**Time Investment**: 15-20 hours/week
**Target**: Complete beginners or those with <2 completed scripts

**Primary Text**: Field - Screenplay
- Master three-act paradigm
- Understand plot points and act divisions
- Learn basic scene construction
- Complete: 1 structured outline

**Supplementary**: Snyder - Save the Cat
- Learn 15-beat structure
- Understand genre patterns
- Practice beat sheet application
- Complete: 1 beat sheet for original idea

- Analyze 5 films using Field paradigm
- Create beat sheets for 3 favorite films
- Outline original screenplay
- Join online screenwriting community

#### Month 3-4: Character & Dialogue
**Primary Text**: Seger - Making a Good Script Great

- Write 5 character-driven scenes

## 6.2 PROBLEM-SOLUTION ROUTING SYSTEM

### Purpose
Quick reference for matching specific problems to appropriate frameworks and texts.

---

### **STRUCTURE PROBLEMS**

#### "My story feels shapeless / lacks structure"
**Primary Solution**: Field - Screenplay (Paradigm)
- Apply three-act structure
- Identify plot points
- Map setup/confrontation/resolution
**Secondary**: Snyder - Save the Cat (Beat Sheet)
**Time**: 2-4 hours for outline restructure

#### "I have structure but it feels mechanical"
**Primary Solution**: McKee - Story (Scene Design)
- Focus on story values
- Build scene by scene causality
- Create organic progression
**Secondary**: Truby - Anatomy (Character-driven structure)
**Time**: 1-2 weeks for restructure

#### "My second act sags"
**Primary Solution**: Field - Screenplay (Midpoint)
- Strengthen midpoint
- Add plot point complications
**Secondary**: Snyder - Save the Cat (Fun and Games → Bad Guys Close In)
**Time**: 2-3 days for mid-section rebuild

#### "My climax doesn't satisfy"
**Primary Solution**: McKee - Story (Crisis/Climax)
- Ensure maximum pressure crisis
- Deliver on story values
- Complete character arc
**Secondary**: Truby - Anatomy (Revelation sequence)
**Time**: 1-3 days for climax redesign

---

### **CHARACTER PROBLEMS**

#### "My protagonist is boring/flat"
**Primary Solution**: Truby - Anatomy (Character web, moral need)
- Define moral weakness
- Create character change arc
- Build opposition relationships
**Secondary**: Seger - Making a Good Script Great (Character dimensions)
**Time**: 3-5 days for character rebuild

#### "Characters all sound the same"
**Primary Solution**: Seger - Making a Good Script Great (Character voice)
- Differentiate speech patterns
- Create distinct vocabularies
- Vary rhythm and word choice
**Secondary**: McKee - Story (Characterization)
**Time**: 1-2 days for dialogue pass

#### "Can't make protagonist likeable"
**Primary Solution**: Snyder - Save the Cat (Save the Cat moment)
- Add sympathetic opening action
- Show kindness or humor
- Create vulnerability
**Secondary**: Seger - Making a Good Script Great (Character sympathy)
**Time**: 1 day for opening scenes

#### "Character relationships feel flat"

## 6.5 TROUBLESHOOTING FRAMEWORKS

### Purpose
When normal approaches aren't working, use these diagnostic frameworks.

---

### **FRAMEWORK 1: THE STUCK WRITER DIAGNOSTIC**

#### **Symptom**: Can't make progress on script

**Diagnostic Questions**:
1. Do I understand my premise clearly? → If NO: Vorhaus (comic premise) or Truby (premise)
2. Do I know my protagonist's journey? → If NO: Field (paradigm) or Truby (character arc)
3. Am I blocked creatively? → If YES: Johnstone (spontaneity exercises)
4. Is the problem technical? → If YES: Seger (troubleshooting) or McKee (craft)
5. Do I lack confidence? → If YES: Apatow (inspiration) or Rosenfield (development)

**Action Protocol**:
- Stop writing for 24 hours
- Complete diagnostic questions
- Address root cause with appropriate text
- Create specific action plan
- Resume with clear direction

---

### **FRAMEWORK 2: THE BORING SCRIPT DIAGNOSTIC**

#### **Symptom**: Script works technically but feels lifeless

**Diagnostic Questions**:
1. Do characters have compelling flaws? → If NO: Truby (moral need) or Vorhaus (comic flaw)
2. Are conflicts meaningful? → If NO: McKee (values at stake) or Truby (opposition)
3. Is dialogue alive? → If NO: Apatow (authenticity) or McKee (subtext)
4. Does story have theme? → If NO: McKee (controlling idea) or Truby (moral premise)
5. Is comedy authentic? → If NO: Apatow (personal truth) or Randazzo (voice)

**Action Protocol**:
- Identify which element is most lifeless
- Study relevant source text intensively
- Rewrite focusing on that element only
- Test with fresh readers
- Iterate until alive

---

### **FRAMEWORK 3: THE UNFUNNY COMEDY DIAGNOSTIC**

#### **Symptom**: Comedy script doesn't generate laughs

**Diagnostic Questions**:
1. Is comic premise clear? → If NO: Vorhaus (comic premise)
2. Are characters exaggerated enough? → If NO: Vorhaus (exaggeration)
3. Do jokes have proper structure? → If NO: Holloway (setup/punchline)
4. Is comedy grounded in truth? → If NO: Apatow (authenticity)
5. Are you committed to absurdity? → If NO: Johnstone (commitment)

**Action Protocol**:
- Test material with live audience if possible
- Mark every intended laugh
- Analyze why each isn't landing
- Rebuild using appropriate comedy framework
- Re-test iteratively

---

### **FRAMEWORK 4: THE CONFUSING STRUCTURE DIAGNOSTIC**

#### **Symptom**: Readers are confused about story

**Diagnostic Questions**:
1. Are act breaks clear? → If NO: Field (plot points)
