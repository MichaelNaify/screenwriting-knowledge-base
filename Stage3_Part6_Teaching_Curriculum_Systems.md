## SYSTEM 1: PEDAGOGICAL FRAMEWORKS & LEARNING MODELS

### 1.1 Core Learning Philosophies

**The Integration Principle (Truby)**
No story element exists in isolation. Effective pedagogy demonstrates connections rather than teaching isolated skills. Students learn structure, character, and theme as an integrated system.

**The Iteration Principle (Seger/Gordon)**
Mastery emerges through repeated application and feedback cycles, not single exposures. Design curricula around progressive iterations of the same concepts at increasing complexity.

**The Revelation Principle (Truby/Johnstone)**
Students learn most when discovering what they already know but cannot yet articulate. Teaching creates conditions for self-revelation rather than information transfer.

**The Practice-First Principle (Chitlik/Field)**
Begin with doing, not theory. Students write before analyzing, experiment before understanding principles. Theory emerges from practice.

**The Error-Positive Principle (Johnstone)**
Learning requires doing it wrong first. Institutionalize error as feedback, not failure. Create psychologically safe environments where mistakes generate data.

### 1.2 Learning Mode Matrix

| Mode | Epistemology | Pedagogy | Assessment | Best For |
|------|--------------|----------|------------|----------|
| **Traditional** | Content transfer | Lecture → Analysis | Performance accuracy | Foundational knowledge |
| **Experiential** | Discovery through doing | Simulation → Iteration | Responsiveness | Skill development |
| **Reflective** | Self-awareness | Practice → Reflection | Growth documentation | Professional maturity |
| **Collaborative** | Distributed cognition | Ensemble → Feedback | Peer evaluation | Creative collaboration |
| **Adaptive** | System translation | Diagnosis → Adjustment | Metric improvement | Advanced mastery |

**Integration Strategy:** Effective curricula cycle through all five modes, with emphasis shifting based on learning objectives and student development level.

### 1.3 The Learning Cycle Architecture

Based on Johnstone, Chitlik, and experiential learning theory:

```
PERCEPTION → PARTICIPATION → EXPERIMENTATION → REFLECTION → INTEGRATION → RENEWAL
```

**Phase Functions:**

| Phase | Cognitive Mode | Observable Effect | Teaching Action |
|-------|---------------|-------------------|-----------------|
| **Perception** | Attentional tuning | Awareness | Demonstrate patterns |
| **Participation** | Social engagement | Trust building | Create safe space |
| **Experimentation** | Embodied practice | Flow state | Provide structure |
| **Reflection** | Metacognitive insight | Self-awareness | Guide analysis |
| **Integration** | Cross-context application | Skill transfer | Connect domains |
| **Renewal** | Iterative curiosity | Sustained growth | Inspire next cycle |

### 1.4 Developmental Stage Model

| Stage | Focus | Learning Objective | Typical Duration |
|-------|-------|-------------------|------------------|
| **Stage 1: Foundation** | Structural grammar | Identify components | 12 weeks |
| **Stage 2: Integration** | Systemic thinking | Connect elements | 12 weeks |
| **Stage 3: Application** | Genre & context | Adapt frameworks | 12 weeks |

**Progression Principle:** Each stage builds on previous foundations. Students should not advance until demonstrating competency thresholds (see Assessment System).

## SYSTEM 2: CURRICULUM ARCHITECTURE & SEQUENCING

### 2.1 The 12-Week Boot Camp Model (Gordon/Rosenfield)

This intensive structure provides measurable deliverables and reflection cycles, creating kinetic pedagogy where learning accelerates through doing.

#### Week-by-Week Curriculum Framework

| Week | Core Focus | Skill Domain | Deliverable | Evaluation Tag |
|------|-----------|--------------|-------------|----------------|
| **1** | Concept & Observation | Pattern recognition | Journal entries ×5 | #pattern-awareness |
| **2** | Character Foundation | Need & weakness | Character profile | #character-grammar |
| **3** | Story Structure Basics | Three-act framework | Beat sheet (12 beats) | #structure-literacy |
| **4** | Scene Construction | Conflict & change | Single scene (3-5 pages) | #scene-craft |
| **5** | Dialogue Fundamentals | Voice & subtext | Dialogue exercise | #language-skill |
| **6** | First Integration | System synthesis | Treatment (5-10 pages) | #integration-1 |
| **7** | Rewriting Principles | Diagnostic analysis | Self-critique | #revision-literacy |
| **8** | Theme & Meaning | Moral argument | Theme statement | #value-articulation |
| **9** | Genre Application | Context-specific tools | Genre scene | #genre-fluency |
| **10** | Collaborative Feedback | Peer review | Table read | #collaboration-skill |
| **11** | Professional Practice | Industry standards | Pitch preparation | #professional-fluency |
| **12** | Final Synthesis | Capstone integration | Complete short script | #demonstrated-mastery |

**Evaluation Weights:** 40% Process Documentation + 40% Creative Quality + 20% Peer Insight

#### Implementation Variations

**Semester Model (16 weeks):** Expand weeks 6, 10, 12 into multi-week units  
**Quarter Model (10 weeks):** Compress weeks 1-2 and 10-11 into combined sessions  
**Year-Long Model (30 weeks):** Triple cycle through foundation, integration, mastery  
**Workshop Intensive (3 days):** Focus on weeks 1, 4, 10 only for rapid skill introduction

### 2.2 Modular Curriculum Design

#### Foundation Modules (Weeks 1-4)

**Module 1A: Story Observation Systems**
- *Learning Objective:* Develop pattern recognition for narrative structure
- *Core Texts:* Field (Paradigm), Truby (22 Steps), Vorhaus (Comic Perspective)
- *Exercises:* Film beat-mapping, story decomposition, pattern journaling
- *Assessment:* Structural literacy quiz + pattern identification exercise

**Module 1B: Character Architecture** 
- *Learning Objective:* Understand character as system of need, weakness, and growth
- *Core Texts:* Truby (Character Web), McKee (Characterization), Seger (Character Arc)
- *Exercises:* Flaw identification, desire mapping, transformation tracking
- *Assessment:* Character profile + arc visualization

**Module 1C: Scene as Unit of Meaning**
- *Learning Objective:* Construct scenes with conflict, change, and purpose
- *Core Texts:* McKee (Scene Design), Field (Scene Structure), Blake (Beat Sheet)
- *Exercises:* Value-shift analysis, turning point identification, scene rewriting
- *Assessment:* Original scene with beat breakdown

**Module 1D: Dialogue & Voice**
- *Learning Objective:* Create character-specific language with subtext
- *Core Texts:* Seger (Dialogue Systems), McKee (Exposition), Vorhaus (Comic Voice)
- *Exercises:* Voice differentiation, subtext generation, rhythm control
- *Assessment:* Dialogue-only scene + voice analysis

#### Integration Modules (Weeks 5-8)

**Module 2A: Structural Integration**
- *Synthesis of:* Character arc + story structure + theme
- *Deliverable:* Treatment showing integrated system
- *Assessment:* Coherence across structural, character, thematic dimensions

**Module 2B: Rewriting as System**
- *Core Texts:* Seger (Rewriting), Chitlik (Seven Passes), Snyder (Beat Refinement)
- *Process:* Diagnostic → Feedback → Revision → Re-evaluation
- *Assessment:* Documentation of revision process + measurable improvement

**Module 2C: Theme & Moral Argument**
- *Core Texts:* Truby (Moral Premise), McKee (Controlling Idea), Field (Theme Through Action)
- *Deliverable:* Thematic analysis + application to student work
- *Assessment:* Clarity of moral argument + integration in story

**Module 2D: Genre as Tool**
- *Core Texts:* Snyder (Genre Categories), Truby (Form Follows Function), Blake (Genre Conventions)
- *Exercise:* Same story premise adapted to three different genres
- *Assessment:* Genre fluency + appropriate tool selection

#### Application Modules (Weeks 9-12)

**Module 3A: Professional Standards**
- *Focus:* Industry expectations, formatting, pitching
- *Core Texts:* Snyder (Professional Practice), Seger (Script Doctor), Gordon (Business Basics)
- *Deliverable:* Professional pitch package
- *Assessment:* Industry-standard formatting + clear communication

**Module 3B: Collaborative Creation**
- *Focus:* Writers' room dynamics, feedback protocols, group authorship
- *Core Texts:* Owen (Collaboration), Johnstone (Ensemble), Rosenfield (Group Mind)
- *Exercise:* Collaborative script development
- *Assessment:* Team dynamics + distributed contribution

**Module 3C: Self-Directed Practice**
- *Focus:* Sustainable writing habits, self-assessment, ongoing development
- *Core Texts:* Chitlik (Discipline), Blake (Daily Practice), Vorhaus (Process Systems)
- *Deliverable:* Personal development plan
- *Assessment:* Evidence of systematic practice

**Module 3D: Capstone Integration**
- *Synthesis:* All previous modules in complete work
- *Deliverable:* 15-30 page script + development documentation
- *Assessment:* Holistic evaluation across all competency areas

### 2.3 Curriculum Sequencing Principles

**Principle 1: Concrete Before Abstract**
Teach through specific examples before general principles. Students analyze existing work before creating original material.

**Principle 2: Simple Before Complex**
Master individual elements before attempting integration. Scene craft precedes full screenplay structure.

**Principle 3: Structure Before Style**
Establish solid architecture before refining aesthetic choices. Beat sheets before dialogue polish.

**Principle 4: Practice Before Theory**
Write, then analyze why it works/doesn't work. Experience generates questions that theory answers.

**Principle 5: Iteration Before Perfection**
Multiple drafts at acceptable quality beats single attempt at perfection. Build improvement through cycles.

**Principle 6: Feedback Before Isolation**
Social learning accelerates development. Peer review and table reads integrated throughout.

## SYSTEM 3: ASSESSMENT & EVALUATION SYSTEMS

### 3.1 Holistic Evaluation Framework

Combines quantitative metrics with qualitative judgment to assess creative work without reducing it to formulaic checklists.

#### Core Evaluation Dimensions

| Dimension | Weight | Focus | Threshold | Assessment Method |
|-----------|--------|-------|-----------|-------------------|
| **Structural Coherence** | 25% | Cause-effect logic | ≥ 9.0/10 | Beat analysis + logic mapping |
| **Character Integration** | 20% | Arc clarity & consistency | ≥ 9.0/10 | Transformation tracking |
| **Emotional Resonance** | 20% | Audience engagement | ≥ 8.5/10 | Peer response + table read |
| **Thematic Clarity** | 15% | Moral argument precision | ≥ 8.5/10 | Value analysis |
| **Professional Execution** | 10% | Industry standards | ≥ 9.0/10 | Format + communication |
| **Creative Innovation** | 10% | Original insight | ≥ 8.0/10 | Uniqueness assessment |

**Aggregate Score Calculation:**
```
Total Score = Σ (Dimension Score × Weight)
Proficiency Threshold: ≥ 8.8/10
Excellence Threshold: ≥ 9.4/10
```

### 3.2 Process-Based Assessment

Evaluates not just final product but documentation of creative process, rewarding systematic development.

#### Required Documentation

**Development Journal** (Weekly entries)
- Observations about craft
- Problems encountered + solutions attempted
- Insights from reading/viewing
- Self-evaluation of progress

**Iteration Log** (Per draft)
- Specific changes made
- Rationale for each change
- Results of changes (what improved/didn't)
- Questions for next revision

**Reflection Essays** (Bi-weekly)
- What you're learning
- How understanding is evolving
- Connections across concepts
- Applications to your work

**Process Assessment Rubric:**

| Criterion | Insufficient (1-2) | Developing (3-4) | Proficient (5-6) | Exemplary (7-8) |
|-----------|-------------------|------------------|------------------|-----------------|
| **Consistency** | Sporadic entries | Weekly entries | Detailed weekly entries | Daily practice documentation |
| **Depth** | Surface observations | Some analysis | Systematic analysis | Sophisticated insight |
| **Application** | No connection to work | Occasional application | Regular integration | Transforms practice |
| **Growth** | No evolution | Slow development | Steady improvement | Accelerating mastery |

### 3.3 Peer Evaluation Systems

Structured peer feedback develops critical thinking while building collaborative culture.

#### Peer Review Protocol (Seger/Chitlik Model)

**Stage 1: Observation (5 minutes)**
Read/experience work without judgment. Note immediate responses.

**Stage 2: Diagnostic Analysis (10 minutes)**
- What works well? (Specific examples)
- Where does engagement drop? (Specific moments)
- What's the core story/theme? (Your interpretation)
- What questions remain? (Confusions, gaps)

**Stage 3: Constructive Feedback (5 minutes)**
- Focus on mechanics, not taste
- Diagnose problems, don't prescribe solutions
- Use "I" statements: "I lost track of..." not "You should..."
- Identify patterns, not isolated issues

**Stage 4: Collaborative Discussion (10 minutes)**
- Writer clarifies intentions
- Reviewers ask questions
- Group generates possible approaches
- Writer decides what resonates

**Peer Evaluation Metrics:**

| Metric | Measurement | Target |
|--------|-------------|--------|
| **Participation Rate** | Active reviewers / total students | ≥ 0.85 |
| **Feedback Quality** | Specificity + usefulness (1-5 scale) | ≥ 4.0 |
| **Collaboration Health** | Anonymous survey (1-10) | ≥ 7.5 |
| **Learning Transfer** | Insights applied to own work | ≥ 70% |

### 3.4 Self-Assessment Tools

#### Diagnostic Checklists (Field/Truby/McKee Synthesis)

**Story Structure Self-Audit**
- [ ] Clear inciting incident within first 15% of story
- [ ] Protagonist's need/goal established early
- [ ] Progressive complications that escalate
- [ ] Midpoint that transforms understanding
- [ ] Crisis forcing ultimate choice
- [ ] Climax that proves thematic premise
- [ ] Resolution showing new equilibrium

**Character Arc Self-Audit**
- [ ] Character's weakness/flaw defined
- [ ] Internal need identified (may differ from external goal)
- [ ] Consistent behavior patterns established
- [ ] Growth opportunities presented
- [ ] Resistance to change demonstrated
- [ ] Transformation earned through action
- [ ] New self demonstrated in resolution

**Scene Efficiency Self-Audit**
- [ ] Scene has clear purpose in story progression
- [ ] Conflict present (internal, external, or both)
- [ ] Value changes from beginning to end
- [ ] Character reveals something or learns something
- [ ] Scene advances plot, character, or theme (ideally all three)
- [ ] Scene could not be cut without damaging story
- [ ] Scene timing appropriate to its function

#### Quantitative Self-Tracking

**Iteration Metrics** (Chitlik Model)
- Number of drafts completed
- Pages revised per pass
- Problems identified per draft
- Problems resolved per draft
- Time per revision cycle
- Improvement rate across drafts

**Practice Discipline Metrics** (Blake Model)
- Daily page count (target: ≥ 2 pages/day)
- Weekly writing hours (target: ≥ 12 hours)
- Scripts analyzed per month (target: ≥ 2)
- Exercises completed per week (target: ≥ 3)

### 3.5 Instructor Evaluation Guidelines

#### Grading Philosophy

**Avoid:** Grading purely on subjective taste or final quality  
**Emphasize:** Process quality, growth trajectory, professional development  
**Balance:** Objective criteria (structure, format) with holistic assessment

#### Three-Tier Evaluation System

**Tier 1: Technical Proficiency (40%)**
- Format compliance (industry standards)
- Structural logic (cause-effect coherence)
- Character consistency (behavioral patterns)
- Objective, rubric-based assessment

**Tier 2: Creative Quality (40%)**
- Emotional engagement (measured via peer response)
- Thematic clarity (articulation of meaning)
- Original insight (avoiding cliché)
- Holistic judgment informed by criteria

**Tier 3: Professional Development (20%)**
- Process documentation (journals, logs)
- Iteration discipline (draft progression)
- Collaborative contribution (peer feedback quality)
- Growth evidence (comparing early/late work)

#### Feedback Protocols (Seger/Chitlik)

**Feedback Should Be:**
- **Specific:** Reference particular moments, not generalizations
- **Diagnostic:** Identify what's not working and why
- **Constructive:** Suggest directions, not prescriptions
- **Encouraging:** Balance critique with recognition of strengths
- **Actionable:** Give writer clear next steps

**Feedback Should NOT Be:**
- **Prescriptive:** Don't rewrite for the student
- **Taste-Based:** "I would have done it this way"
- **Overwhelming:** Too many issues creates paralysis
- **Discouraging:** Criticism without hope for improvement

**Feedback Delivery Cycle:**

```
WRITTEN NOTES (1-2 pages) → CONFERENCE (15-30 min) → STUDENT REFLECTION (written) → NEXT DRAFT
```

### 4.4 Instructor Protocols & Best Practices

#### The Practice-First Protocol (Chitlik)
1. Students write BEFORE receiving theory
2. Experience generates authentic questions
3. Theory provides frameworks to understand practice
4. Application reinforces integration
5. Reflection completes learning cycle

#### The Diagnostic-First Protocol (Seger)
1. Identify root problems, not symptoms
2. Diagnose cause before suggesting solution
3. Let writer discover answers through guided questions
4. Provide frameworks, not prescriptions
5. Track whether solutions address root cause

#### The Status-Aware Protocol (Johnstone)
1. Flatten hierarchy between teacher/student
2. Invite student agency and co-design
3. Play in exercises alongside students
4. Share vulnerability and learning process
5. Model status flexibility

#### The Iteration Protocol (Gordon/Chitlik)
1. Set clear deadlines and honor them
2. Require multiple drafts with documentation
3. Measure improvement, not perfection
4. Celebrate progress and learning
5. Archive data for curriculum improvement

## SYSTEM 6: FEEDBACK SYSTEMS & LEARNING ANALYTICS

### 6.1 Multi-Level Feedback Architecture

Effective learning requires feedback from multiple sources at different timescales.

#### The Three-Loop Feedback Model (Owen/Seger)

**Loop 1: Immediate (Micro-Loop)**
- **Source:** Real-time practice, table reads, writing exercises
- **Frequency:** During each session
- **Function:** Calibrate understanding, correct misapprehensions
- **Example:** "That joke didn't land—let's analyze the setup-punchline relationship"

**Loop 2: Developmental (Meso-Loop)**
- **Source:** Instructor feedback, peer review, draft evaluation
- **Frequency:** Weekly or per-draft
- **Function:** Guide revision, address patterns, track progress
- **Example:** "Your character arcs are strong, but scenes need clearer value shifts"

**Loop 3: Summative (Macro-Loop)**
- **Source:** Final evaluations, portfolio review, competency assessment
- **Frequency:** End of module/semester
- **Function:** Certify achievement, identify next development phase
- **Example:** "You've achieved proficiency in structure; next phase focuses on dialogue"

#### Feedback Delivery Framework

**Written Feedback Best Practices:**
- **Length:** 1-2 pages for substantial work
- **Structure:** Strengths first, then issues with specific examples, then suggested directions
- **Tone:** Professional but encouraging
- **Specificity:** Reference page/scene/line numbers
- **Balance:** 60% diagnostic, 30% directional, 10% prescriptive

**Conference Feedback Best Practices:**

## SYSTEM 7: WORKSHOP & CLASSROOM STRUCTURES

### 7.1 Classroom Architecture Principles (Johnstone)

Physical and social environment design significantly impacts learning outcomes.

#### Physical Space Design

**Optimal Configuration:**
- **Seating:** Circle or U-shape (no desks as barriers)
- **Visibility:** All students can see each other
- **Movement:** Open space for physical exercises
- **Technology:** Screen for film analysis, but removable
- **Materials:** Whiteboards for communal brainstorming

**Psychological Implications:**
- Circle seating flattens hierarchy
- Visibility creates accountability and connection
- Movement space enables embodied learning
- Flexible setup allows activity variety

#### Social Environment Design

**Status Management:**
- Instructor participates in exercises alongside students
- Rotate leadership roles (different students lead exercises)
- Normalize vulnerability and error
- Celebrate risk-taking over perfection

**Trust Building:**
- Confidentiality agreements for work shared in class
- No mockery or personal attacks ever tolerated
- "Yes, and..." principle from improv
- Constructive-only feedback protocols

**Community Formation:**
- Regular check-ins (personal + professional)
- Shared meals or social time
- Collaborative projects
- Alumni network integration

### 7.2 Session Structure Templates

#### Standard 3-Hour Class Session

**Minutes 0-20: Warm-Up & Community**
- Physical warm-up or improv exercise (Johnstone)
- Creative writing prompt (5 min timed writing)
- Pair-share responses (builds trust, generates ideas)
- Transition to lesson

**Minutes 20-50: Core Lesson**
- Brief lecture on concept (15 min max)
- Film clip analysis demonstrating principle
- Q&A and discussion
- Connect to previous learning

**Minutes 50-100: Application Workshop**
- Exercise applying concept (individual writing: 20 min)
- Small group work (3-4 students: 15 min)
- Sharing and feedback (15 min)
- Revisions based on feedback (optional: 10 min)

**Minutes 100-140: Integration Activity**
- Table read or scene performance (if applicable)
- Peer review sessions (structured protocol)
- OR: Individual consultations while others work
- OR: Guest speaker or masterclass

**Minutes 140-170: Closing & Reflection**
- Group debrief: What worked? What was challenging?
- Individual reflection writing (5 min)
- Preview next session
- Assign homework/reading

#### Intensive Workshop (Full Day)

**9:00-10:30: Foundation Session**
- Concept introduction + examples
- Initial exercise + feedback

**10:30-10:45: Break**

**10:45-12:30: Deep Practice**
- Extended writing time
- Individual consultations available
- Self-directed application

**12:30-1:30: Lunch (communal if possible)**

**1:30-3:30: Peer Workshop**
- Structured peer review sessions
- Revision based on feedback
- Group sharing of revisions

**3:30-3:45: Break**

**3:45-5:30: Integration & Performance**
- Table reads or presentations
- Group analysis and celebration
- Reflection and next steps

### 7.3 Exercise Design Framework

Effective exercises are:
- **Purposeful:** Clear learning objective
- **Bounded:** Specific constraints (time, page count, requirements)
- **Achievable:** Appropriate to skill level
- **Progressive:** Builds on previous learning
- **Transferable:** Skills apply beyond the exercise

#### Exercise Templates by Domain

**Structural Literacy Exercises:**

*Beat Mapping* (30 min)
- Watch 15-minute film segment
- Identify and write down each beat
- Compare with partner and discuss differences
- Instructor reveals "answer" and discusses ambiguities

*3-Act Sculpture* (45 min)
- Given premise, create 12-beat outline
- Must hit: Inciting incident, Act break, Midpoint, Crisis, Climax
- Share with partner for structural feedback
- Revise based on feedback

**Character Development Exercises:**

*Flaw Archaeology* (20 min)
- Choose public figure or fictional character
- Write character's greatest flaw in one sentence
- Write three behaviors that demonstrate this flaw
- Write one action that would require confronting/overcoming flaw

*Relationship Web* (45 min)
- Create protagonist + four supporting characters
- Define specific relationship (with history) between each pair
- Ensure characters have competing needs
- Write one scene showing two of these relationships

**Dialogue Exercises:**

*Voice Differentiation* (30 min)
- Write same basic information delivered by three different characters
- Each must reveal character personality and background through word choice/rhythm
- No stage directions allowed
- Read aloud to test distinctiveness

*Subtext Generation* (45 min)
- Write scene where characters say opposite of what they mean
- Clear situation requiring dishonesty (politeness, secrecy, manipulation)
- Audience should understand truth through contradiction between words and behavior

**Scene Craft Exercises:**

*Value Shift Focus* (30 min)
- Write 2-page scene with clear value change (love→hate, hope→despair, etc.)
- Chart the specific moment shift occurs
- Identify each beat that contributes to shift
- Rewrite to increase sharpness of shift

*Conflict Escalation* (45 min)
- Start scene with small disagreement
- Escalate tension through 3-5 beats
- Each beat raises stakes or reveals new information
- End with clear change in relationship/situation

**Comedy-Specific Exercises:**

*Rule of Three Drill* (15 min)
- Given setup, generate 10 different three-item lists
- Read aloud to test rhythm and surprise
- Identify which worked and why

*Game Identification* (30 min)
- Watch comedy scene from film/TV
- Identify the "game" (pattern being repeated)
- Write your own scene using same game structure but different content

### 7.4 Facilitation Techniques

#### Managing Group Dynamics

**When Discussion Stalls:**
- Use think-pair-share (individual reflection → pairs → whole group)
- Call on specific students rather than waiting for volunteers
- Use anonymous responses (index cards, online poll)
- Break into smaller groups

**When Domination Occurs:**
- Set "take a turn/pass a turn" rule (if you speak twice, you must yield next opportunity)
- Direct questions to quiet students
- Use written exercises to level playing field
- Private conversation with dominating student

**When Conflict Emerges:**
- Reframe as learning opportunity about perspective
- Focus on craft issues, not personal taste
- Model disagreement with respect
- Take conversation offline if becoming destructive

**When Energy Drops:**
- Physical movement break
- Switch from lecture to activity
- Humor or surprise (show unexpected clip)
- Early release if truly unproductive

#### Question-Asking Strategies

**Socratic Questioning** (guide discovery rather than lecturing):
- "What do you think is happening in this moment?"
- "Why do you think the character made that choice?"
- "What would happen if we changed X?"
- "How does this connect to what we learned last week?"

**Diagnostic Questioning** (identify problems):
- "Where does your attention drift in this scene?"
- "What questions do you have about the character?"
- "What are you confused about?"
- "What feels incomplete?"

**Generative Questioning** (spark ideas):
- "What are ten different ways this scene could end?"
- "What would happen if the character wanted the opposite?"
- "How would this work in a different genre?"
- "What rule could we break here?"

## SYSTEM 8: PROFESSIONAL INTEGRATION & CAREER DEVELOPMENT

### 8.1 The Writer's Career Arc (Owen/Seger)

Professional development is lifelong learning. Pedagogy should prepare students not just for first job but for sustainable career.

#### Career Stages & Development Needs

**Stage 1: Apprentice (Years 0-3)**
- *Focus:* Foundational skills, portfolio development, industry literacy
- *Education Needs:* Structured curriculum, regular feedback, mentorship
- *Output:* Sample scripts, short films, spec episodes
- *Support:* Writing groups, competitions, fellowships

**Stage 2: Emerging Professional (Years 3-7)**
- *Focus:* First paid work, professional network, reputation building
- *Education Needs:* Advanced workshops, industry connections, business skills
- *Output:* Commissioned work, produced credits, professional collaborations
- *Support:* Agents, managers, production relationships

**Stage 3: Established Professional (Years 7-15)**
- *Focus:* Consistent work, creative control, career sustainability
- *Education Needs:* Specialized mastery, leadership skills, creative renewal
- *Output:* Series credits, features, show-running/producing
- *Support:* Industry reputation, professional network, financial stability

**Stage 4: Master Practitioner (Years 15+)**
- *Focus:* Legacy work, mentorship, industry contribution
- *Education Needs:* Continuous innovation, teaching development, system thinking
- *Output:* Signature projects, mentoring others, thought leadership
- *Support:* Established reputation, freedom to take risks, giving back

### 8.3 Mentorship Systems (Owen Model)

Effective career development requires connection to working professionals.

#### Three-Tier Mentorship Architecture

**Tier 1: Peer Mentorship** (Student-to-Student)
- **Duration:** Throughout program
- **Function:** Mutual support, accountability partners, peer feedback
- **Structure:** Self-organized or instructor-facilitated pairs/groups
- **Outcome:** Collaborative skills, friendship networks, shared learning

**Tier 2: Near-Peer Mentorship** (Recent Graduate to Student)
- **Duration:** 6-12 months
- **Function:** Industry transition guidance, practical advice, realistic expectations
- **Structure:** Monthly check-ins, email access, occasional in-person meetings
- **Outcome:** Demystified career path, professional connections, job opportunities

**Tier 3: Professional Mentorship** (Established Writer to Student)
- **Duration:** 1-3 years (may be ongoing)
- **Function:** Career guidance, industry access, script feedback, advocacy
- **Structure:** Quarterly meetings, script notes, introductions to network
- **Outcome:** Industry credibility, high-level feedback, career acceleration

#### Mentorship Best Practices

**For Mentees:**
- Come prepared with specific questions/needs
- Respect mentor's time (be punctual, prepared, grateful)
- Act on advice and report back on results
- Understand this is professional relationship with boundaries
- Pay it forward when you're established

**For Mentors:**
- Set clear expectations about availability
- Be honest about industry realities
- Make specific introductions when appropriate
- Provide actionable feedback
- Celebrate mentee successes
